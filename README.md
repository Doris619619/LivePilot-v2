# LiveNest

在网页选择素材、授权频道并控制直播；Windows 客户端配置本机 OBS、运行 Agent 和检查故障。支持多台电脑，每台可使用多个独立 OBS。

**0.1.19 正式发布**：汇总已合并的OBS检查、网页工作台、配额保护及异常恢复修复。安装包、Cloud、网站下载、源码摘要及实际验收边界见 [0.1.19发布记录](docs/desktop/0.1.19发布.md)。

YouTube 配额异常的源码审计、服务器与备份证据、离线计数测试和 100 路容量计算见 [YouTube API 配额异常消耗审计报告](docs/YouTube_API配额异常消耗审计报告.md)。该报告保留修复前的证据与结论，后续实现见下方说明。

后续已实现 [YouTube 配额保护与管理员数据台](docs/YouTube配额保护与数据台.md)：统一项目预算、调用日志、停播停止平台轮询、短连接退避和离线本机停止。管理员在“总览 → YouTube 配额”查看趋势、筛选与导出日志；首次接入须核对当日用量基线。Cloud交付与正式安装器见 [0.1.19发布记录](docs/desktop/0.1.19发布.md)，Agent侧能力需升级客户端后启用；配额策略与验收边界仍见该功能文档。

## 故障恢复

新增 OBS 先保存在“待配置 OBS”，验证成功后才登记到网页。失败可重试、修正手动连接或撤销新增；撤销只归档配置，不删除 OBS 文件。旧实例及频道绑定保留。“修复连接（先关闭 OBS）”仅修改已停止且归属匹配的自有实例，并要求已配对设备取得维护锁；正常启动沿用原端口和密码。

点击“启动并检查”后，目标 OBS 在连接等待期间只显示启动进度，不把端口尚未就绪的轮询结果当作启动失败；结束后按最新检查显示成功或故障，其他 OBS 的问题仍分别保留。此反馈修正待随新版客户端发布，已发布的 0.1.14 尚不包含。

网页素材上传新增“查询未结束的上传”，可找回创建失败或响应丢失的记录并查询、取消。云端只根据 Agent 确认的完成、取消或有效的不存在结果解除上传维护阻塞；未知结果不会因七天到期而自动放行。客户端“检查电脑”读取实际监听地址与防火墙有效策略，无法确认隔离时明确提示核查。

配对只需网页生成新码、复制到客户端并点击“连接”。旧电脑被移除后也能使用新生成的码，无需查找旧设备或专属码；客户端证明原身份后，云端自动恢复原电脑，保留 OBS、素材、密钥和本机授权文件。配对码十分钟有效、只可认领一次；响应丢失可由同一电脑重试。成功后隐藏表单，邀请占位不混入直播设备列表。网页“移除电脑”会释放它占用的频道，之后可连接到任意电脑；本机文件保留，不会停止 OBS 或直播。普通离线不会释放频道；另一台电脑不能凭新码接管原身份。旧 Agent 的原配对协议和恢复入口继续兼容。

内置 OBS 资源缺失、手动路径不存在和解压不完整均提供具体提示；初始化失败保留候选以便重试。已经配置的 OBS 缺失时不会自动覆盖旧目录。

已配对却一直等待连接：新版内置 Agent 启动时沿用 Windows 系统 HTTP/HTTPS 代理，本机 OBS 保持直连。连接失败及时显示原因并允许重试；后台继续重连。网络故障无需删除设备或重新配对，更改系统代理后需重新打开客户端。显式 HTTPS 代理环境变量优先；暂不支持仅 SOCKS 的系统代理。

托盘“退出”不再依赖云端维护锁：断网也可在已接收任务处理完毕后退出，OBS 保持运行。配置中或 Agent 尚未确认退出时保留客户端并提示重试，不强杀进程。客户端内“重启更新”不依赖云端维护许可：先检查全部本机 OBS，排空并确认 Agent 退出，再复查 OBS 与配置落盘；失败保留客户端，必要时恢复原 Agent 连接。OBS 配置变更仍要求云端维护许可。旧版若卡在重启更新，可正常退出客户端后从官方发行页下载新版覆盖安装，保留原数据目录；不要强杀 Agent 或 OBS。

兼容旧 Agent 协议。网页提供公开 `/download` 页面，直接下载与云端版本配套的 Windows 安装器，并提供历史发行入口；网站静态下载与 GitHub 自动更新源需在发布时分别同步。上传区按文件、进度、操作排列，历史恢复入口折叠；没有素材时可点“添加视频／音乐”，自动带入对应 OBS，并保留进行中的上传。详见 [故障恢复与验收](docs/故障恢复与验收.md) 和 [网页部署记录](docs/desktop/网页故障恢复部署.md)。

## 普通视频发布

把一个批次复制到所选电脑的 `<LiveNest 数据根>/Publishing/Inbox`；每条视频的文件直接放在一个子文件夹中（如 `Inbox/我的批次/001/video.mp4`），可添加音乐、`cover.jpg/png`、`title.txt` 和 `description.txt`。网页进入“发布视频”：**检测并检查素材 → 配置与排期 → 确认计划 → 自动执行**。发布账号独立添加和授权，可与直播使用不同频道；同一电脑可绑定多个发布账号。已到达的步骤可点击返回，保留时间与文案；第二步支持每周不同时间，自动跳过已知占用时刻。确认页用日历预览，也可切换列表逐项核对；异常包须修复或明确暂不发布。进入自动执行后仍可点“配置与排期”，预览并确认未完成视频的新排期，沿用原上传任务；手动时间保持，远端生效等待设备确认。“我的发布”用独立频道分区、固定标识色和头像展示各批次进度；历史采用紧凑列表，支持搜索、结果筛选和单项详情，计划时间与真实公开结果分别显示。

准备素材页会自动读取目标电脑的真实 Inbox 路径，支持复制路径；电脑客户端可以打开发布目录。时区使用可搜索下拉框，支持城市、IANA 名称和 UTC 偏移。执行页直接显示每条视频的准备、上传 YouTube、处理、确认排期、等待公开和公开结果，操作与诊断按需展开。右上角成员名称可切换本浏览器已登录的账号；新增账号首次验证密码，之后切换无需重新登录，退出仅撤销当前账号。网页切换同步其他标签页并阻止旧成员页面误用新身份发送控制。

“我的发布”每个批次右侧直接提供“删除批次”，详情顶部也保留该入口。确认后停止未公开内容，设备确认取消后才移出总览；设备离线时提示打开该电脑的 LiveNest，维护中等待维护结束，取消失败保留原因与重试入口。已公开视频、本地素材、上传恢复记录和发布历史保留，删除不等于下架视频或搬移素材。详见 [批次删除与验证](docs/发布批次删除.md)。

带音乐的包由 Agent 在本机生成最终视频，视频字节不经过 Cloud。将成对的 `ffmpeg.exe` / `ffprobe.exe` 放在数据根下的 `tools`，也支持 PATH；未安装只影响需要合成的包。旧视频任务、OAuth、断点与远端排期保留。新版发布包要求 Cloud 和 Agent 均更新；发布流程无需管理员额外打开功能或勾选验收。Google 对未审核 API 项目的实际限制仍生效，客户端开关不能代替项目审核。整批确认完成后可手动归档，原恢复文件保留。详见 [发布包、排期与验收](docs/YouTube普通视频发布.md)、[工作台修复与验证](docs/发布工作台易用性修复.md)；已公开安装器状态见 [0.1.11 记录](docs/desktop/0.1.11发布.md)。

本分支继续精简工作台、发布、管理和桌面 UI：压缩重复层级，设置与账户统一置底，配对使用独立对话框，保留全部业务流程与异常恢复。审计取舍和验证边界见 [前端 UX 精简审计](docs/前端UX精简审计.md)。本轮进一步复审设置、保存中状态、账号加载、表单语义与导航路径，逐项清单见 [前端细节复审](docs/前端细节复审.md)。这些变更尚未合并发布。

## 报错与恢复

创建场次前失败不会再由后台刷新覆盖新选素材；第二场前置检查失败保留上一场已结束的事实。平台已结束且 OBS 已停时，可在素材锁定提示旁确认结束并解锁。推流对象确实已被删除时，仅在 OBS 已停且原广播尚未开播的条件下重建连接，临时查询失败不替换对象。异常场次、上传、发布与桌面配置的修复范围及验收边界见 [异常恢复修复与验证](docs/异常恢复修复与验证.md)。本次不调整配额、轮询节拍或计费策略。

0.1.3 历史记录：当时网页云端同步部署故障恢复版本，下载页同步已公开的 0.1.3 安装器；部署方式与验收边界见 [0.1.3 网页云端部署](docs/desktop/0.1.3网页云端部署.md)。当前版本与部署状态见本页开头的 0.1.13 记录，旧版本记录保留作追溯。

网页和桌面按原电脑、OBS 或上传文件展示事实、结果确定程度、操作步骤与恢复入口。**设备在线只表示 Agent 与云端通信，不等于 OBS 控制已连接或正在推流**。OBS 未监听时先检查对应 OBS 的 WebSocket 设置，不能据此认定防火墙故障。

- 客户会话失效才重新登录。设备凭据、频道授权、配额和网络故障分别处理；服务器故障保留原登录和频道记录。
- 结果待核对时先“重新检查／查询本次操作”。只读查询不停止直播、不再次开播、不自动重新上传或校验。
- 素材目录读取失败不会显示为空库。上传收起后仍显示失败摘要；“查询校验状态”只读，“重新提交校验”需明确点击。
- 数据迁移分别反馈复制、切换与重连。已切换但重连失败时使用“重新连接并恢复”，无需再次迁移，原目录保留。
- 可复制脱敏诊断摘要交给管理员，摘要不含密码、令牌、原始异常、绝对路径或表单输入。
