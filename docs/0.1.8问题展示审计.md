## E01–E26 复核

| 范围 | 本轮结论与证据 |
| --- | --- |
| E01–E03 | 防火墙检查与控制连接分离；只读检查不隐式重试开播。problem-readiness、obs-diagnostics、obs-firewall |
| E04–E10 | 保留认证、权限、配对、启动与保存失败语义；账号迁移撤销会话但不重置密码或业务。完整 verify 与 accounts-management |

| E17 | 原任务成功或失败后解除旧请求等待错误，未知结果仍阻止重发；账号写成功与刷新失败分离 |
| E18–E20 | 保留 OAuth 原目标与维护事务；帮助更新至五步和本机保护入口 |
| E21–E23 | 管理汇总不把技术检查当故障；管理员账号 API 独立校验来源、权限、锁和输入 |
| E24–E26 | 保留安装更新校验、迁移事务与恢复动作白名单；技术报告独立脱敏导出。完整 verify、Windows installer CI |
