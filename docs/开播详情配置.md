# 网页开播详情

实例工作台分为「直播内容 / 音视频 / 发布设置」三个页签，切换保留草稿；右侧集中封面预览、封面上传、运行状态与开播控制，窄屏顺序堆叠。设备与频道收在顶部折叠区。配置包含：标题、说明、封面、公开范围、观众和播放列表。右侧预览只展示信息，不发起直播。标题必填，最多 100 字；说明最多 5000 字，均不允许尖括号。公开范围默认为「公开」，也可主动选择「不公开列出」或「私密」。儿童内容按实际选择。

封面支持 JPG / PNG，产品限制为 2 MB。先上传到选定电脑的 Agent 实例，再在开播前设置到 YouTube；浏览器只保存封面标识和名称。频道需要具备 YouTube 自定义缩略图权限。移除封面表示本次不设置自定义封面，不会删除已有 YouTube 视频或清理本机文件。

点击「读取频道列表」后可多选当前授权频道拥有的播放列表。没有列表时先到 Studio 创建。新增场次将加入所选列表；失败重试先查询已有成员，避免重复插入。

草稿保存在当前浏览器标签页的 sessionStorage，按电脑和 OBS 实例隔离；刷新和授权往返可恢复，关闭标签页不保证保留。它不是跨浏览器共享的模板。图片预览不进入 sessionStorage，刷新后保留已上传名称。开播受理后，实际配置由 Agent 保存并通过心跳回显，重试锁定原场次的素材和详情。

## DeepSeek 英文文案

在「AI 生成英文文案」中输入 `lofi`、`jazz` 或简短主题，点击「生成并填入」。生成结果只替换标题和说明，可继续编辑或撤销最近一次填入。失败保留原文案，不自动重试付费请求。

可在运行 Agent 的环境设置 `DEEPSEEK_API_KEY`，本机网页开发使用被 Git 忽略的 `.env.local`。也可在「DeepSeek 设置」粘贴 API Key 并保存，实例密钥优先于环境密钥；密钥按实例加密保存在 Agent 的 `deepseek.enc`，网页只查询是否已配置。云端投递记录和 Agent 工作日志也保持加密，审计仅记录操作类型。浏览器不将 Key 放入 sessionStorage/localStorage，成功保存后清空输入框。保存成功仅确认落盘，实际生成时才验证余额和凭据。

Agent 只向固定官方地址 `https://api.deepseek.com/chat/completions` 发送关键词，使用 `deepseek-flash` 非思考模式和 JSON 输出；不发送 YouTube Token、频道资产或 OBS 信息。模型和请求参数依据 [DeepSeek 官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion/) 核对。生成文案不会自动触发开播。

本地预览从 `.env.local` 仅加载 DeepSeek 密钥，并复用正式生成模块。配置后点击生成会调用官方接口，未配置时返回明确标注的演示文案。预览的保存 Key 接口仍禁用。自动化 UI 回归拦截生成请求为合成响应，不消耗真实余额。

## 默认值与升级

- 网页新草稿明确使用 `public`，用户保存的其他选择优先；环境变量不覆盖显式网页选择。
- 不带新详情的旧调用仍读取 `LIVEPILOT_PRIVACY`；未设置时的缺省值改为 `public`，已明确配置的值保留。
- 云端和 Agent 需要共同升级。Agent 心跳声明 `configuration.broadcastDetails`；云端拒绝给旧 Agent 投递新详情和封面任务，返回升级提示。安装版尚需重新打包发布，此分支不会自动修改线上服务或正在运行的安装版。
- 旧场次和旧授权保持兼容。现有直播不会因默认值变化自动变为公开。

## 执行与恢复

`Selection.broadcast` 经 HTTP 和远程任务双重白名单校验，命令记录与幂等指纹包含完整详情。Agent 创建时暂用唯一恢复标题并写入公开范围、儿童内容及说明；持久保存 Broadcast ID 后再应用用户标题、封面与播放列表。创建响应丢失时仍可用唯一标题查回原场次。所有详情准备成功后才启动 OBS 推流，失败可按原参数重试。

`/api/broadcast-assets` 保留成员鉴权、同源检查与目标电脑归属校验。封面采用有大小上限的投递任务，持久文件为实例数据目录内 `thumbnail-<UUID>.json`；不接受浏览器路径或任意下载 URL。图片原始数据不进入控制命令、状态心跳、审计日志或浏览器 DTO。准备过程中不记录原始 Google 请求或错误。

## Studio 中的功能

年龄限制、字幕、片尾画面、卡片、付费宣传与联合创作在「更多 YouTube 设置」中提供 Studio 入口，不显示虚假的已同步开关。部分功能只适用于直播回放；本次不实现字幕文件或实时字幕工作流。

官方接口参考：[创建直播](https://developers.google.com/youtube/v3/live/docs/liveBroadcasts/insert)、[更新直播详情](https://developers.google.com/youtube/v3/live/docs/liveBroadcasts/update)、[上传缩略图](https://developers.google.com/youtube/v3/docs/thumbnails/set)、[加入播放列表](https://developers.google.com/youtube/v3/docs/playlistItems/insert)。
