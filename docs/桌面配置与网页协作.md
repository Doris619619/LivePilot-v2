# 桌面配置与网页协作

LiveNest 负责本机 OBS 和 Agent；网页负责频道授权、素材与开停播。直播电脑不需要系统 Node、Git、Docker 或预装 OBS。以下数据位置与 OBS 简化流程随本次分支交付，未表示公开安装器已经更新。

## 安装时选择两条路径

1. 从下载页获取完整 Windows x64 安装器。
2. 选择程序安装位置，保存 LiveNest.exe、Agent、内置 Node 和干净 OBS ZIP。
3. 在“LiveNest 数据保存位置”页选择父文件夹。选 `D:\` 得到 `D:\LiveNest`；选 `D:\直播` 得到 `D:\直播\LiveNest`。向导显示最终路径，不需要手工创建 obs、media 等子目录。
4. 程序安装目录和数据目录不能相同或互相包含。已有未知文件、目录链接、权限不足等情况会拒绝继续。
5. 升级或重装沿用原数据位置。普通卸载保留数据和定位记录；需要搬迁时在应用设置中操作。

D 盘只是新安装的建议值，必须在向导确认；不会静默回退生成身份。未经过安装向导的首次启动，登录后先选择数据位置。已选数据盘失联时应连接原盘，程序不会另建身份覆盖原配置。

## 本机数据

```text
LiveNest/
  .livenest-root.json
  obs/main/                       # 后续实例为 obs_<随机ID>/
  media/<instanceId>/videos/
  media/<instanceId>/music/
  media/<instanceId>/.uploads/     # 现有上传及恢复数据
  state/desktop/settings.json     # Windows 当前用户加密配置
  state/                          # main 状态、令牌及其他业务记录
  state/instances/<instanceId>/
  logs/
  temp/                           # 有需要时使用
```

AppData 的 `data-location.json` 只记录数据位置和根 ID，不保存凭据。旧版 AppData 的加密配置验证迁入后保留为兼容备份，后续使用根目录中的新配置。Electron 自身可再生缓存仍由系统管理，不是设备身份或直播业务数据。Windows 用户级密文不能通过拷贝到其他账户或电脑绕过身份保护。

## 第一次准备和添加 OBS

用管理员分配的**客户账号**登录客户端。管理员账号使用管理员网页；客户端与网页登录会话独立。退出登录锁住界面，Agent 继续运行；关闭窗口进入托盘。

在设备配置或本机 OBS 点击“准备第一个 OBS”。程序保存 main 候选、生成独立随机密码和空闲端口、从安装包的干净 ZIP 解压、启用 portable，然后真实启动并检查。成功后才显示“OBS 1 已配置”。

已有 OBS 时，在“本机 OBS”实例列表下点击“添加 OBS”。每次使用干净 ZIP，不复制 OBS 1 的场景、频道、素材或授权。添加前所有相关 OBS 必须没有直播或录制，已配对设备还需要云端确认上传、授权和任务空闲。无需重新配对电脑。

默认参数保持现有行为：LIVE 场景，VIDEO 与 MUSIC 媒体源；1280×720、30 FPS、x264、4000 Kbps，音频 48 kHz / 128 Kbps；视频循环并关闭视频原声，全局桌面和麦克风采集关闭。创建只启动 OBS，不调用开始直播。

失败候选保留 ID、密码和文件。点击对应“重试配置”，不会新增另一个身份。首次 main 失败时先“继续准备第一个 OBS”；撤销只归档，使用“恢复配置”继续。已完成实例的端口、路径和连接修复位于“OBS 详情与修复”。修复前手工关闭目标 OBS，程序不强杀用户进程。

## 配对、频道和素材

1. 在网页生成新配对码，复制到客户端“连接网页”，点击连接并等待真实在线状态。
2. 在网页为各 OBS 授权不同频道。OAuth 同意由频道持有人完成；其他 OBS 的授权不会被复制。
3. 上传视频和音乐到所选电脑、所选 OBS，等上传完成后选择播放素材。
4. 检查就绪后，由用户主动点击网页“开始直播”，核对真实音画；已配置不等于真实直播验收完成。

旧电脑可用新配对码证明并恢复原身份，保留设备 ID 与原频道授权；普通断网无需重新配对。新增通过维护锁同步 inventory、重启 Agent 并确认心跳，不重新分配电脑身份。维护或 inventory 响应不确定时，保留原记录并使用“重新连接并恢复”。

## 更改 LiveNest 数据位置

设置统一显示“LiveNest 数据位置”、实际路径、“打开文件夹”和“更改位置”。没有正式实例、候选、归档、身份或业务文件时可以直接选择。

已有数据时，先结束所有直播、录制、上传和授权，关闭所有相关 OBS，包括失败候选与归档实例。选择新的父文件夹并确认“复制并切换”。程序检查维护、停止 Agent、完整复制、校验目录清单／文件大小／SHA-256、更新托管 exe 和场景素材路径，最后切换配置并恢复 Agent。**原目录始终保留**。

失败前后以已提交的定位记录为准：切换前失败继续使用旧目录；切换后连接失败保留新目录与维护状态供重连。半成品目标保留 `.livenest-migration.json`，重试选择新空目录；不自动删除失败副本。外部手动 OBS 不改写；其场景仍依赖旧数据位置时需先人工处理。不要直接编辑路径字符串或自行删除原配置。

## 高级兼容能力

“高级选项 / 接入已有 OBS”默认折叠，保留快速扫描、完整扫描、浏览复制已有 OBS，以及输入端口和密码直接连接专用便携 OBS。复制只取程序内容，不复制原场景或推流授权；直接连接只检查现有标准场景，不自动改写。

手动候选连接错误时可以修正端口／密码。OBS 缺失、解压中断、资源不完整都有对应错误和重试入口，已配置的目录不会因重新安装或准备而被覆盖。离线帮助仍保留截图教程。

托盘退出会等待已接收任务排空和 Agent 退出，OBS 保持运行。软件更新仍受维护保护。OBS 仅供本机控制，不应增加公网端口转发或放宽防火墙。

详细实现和分层验收见[本地数据与独立 OBS](desktop/本地数据与独立OBS.md)。
