# 直播与视频发布的连续工作区

## 用户行为

- 左侧「直播工作台 / 视频发布」始终保持同一位置，设置和账号固定在左下角。设备定位和发布管理分别作为次级导航。
- 首次访问模块才加载它；访问过的模块切走后保留编辑状态，返回恢复各自的滚动位置。标题、说明、生成主题、直播步骤、发布账号、批次、排期、未保存的发布配置及当前子页不因切换而重建。
- 地址仍为 `/workspace` 和 `/publishing`，支持直接打开、收藏和浏览器前进后退。
- 浏览器素材上传在两个模块间切换时继续执行。发布区侧栏显示上传进度、校验或完成状态，点击可回到上传区。
- 离开工作区的预览播放器停止并释放媒体；设备预览会话关闭。返回不会自动播放。后台状态刷新降低频率，重新进入立即查询最新状态。

## 实现与边界

`src/app/(workbench)/layout.tsx` 持有一次登录门禁和 `Workbench`。路由页只保留元数据；`Workbench` 惰性挂载两个模块，并将已访问模块保留在内存。两边的次级导航投递到同一个侧栏，只有当前模块可见、可聚焦。

上传组件随已挂载的直播工作区存活，模块切换不会调用卸载时的取消逻辑。上传仍沿用同一文件、幂等创建身份、服务器确认偏移和校验流程；不会为切换补发或重建任务。

位置按模块分别记录，导航使用 `scroll={false}`，恢复时立即定位并禁用工作区的浏览器自动滚动锚定。隐藏模块保留表单状态，但不保留媒体播放器的网络资源；弹窗和浮层不会穿透到另一个模块。

身份验证、设备权限和直播/发布账号边界保持不变。退出、登录过期或切换登录账号会销毁旧工作区并取消浏览器上传；保留编辑状态不允许跨账号延续。刷新页面、关闭标签页、离开这两个路由不是后台上传承诺范围，仍按既有草稿缓存和断点续传流程恢复。

## 侧栏分组层级统一

参考 [VS Code 官方侧栏规范](https://code.visualstudio.com/api/ux-guidelines/sidebars) 的分组边界与用户指定的 [GitLab 官方侧栏截图](https://docs.gitlab.com/tutorials/left_sidebar/img/sidebar_v18_11.png) 中的整行入口、右侧箭头和可展开分组；以下尺寸、颜色和默认展开策略是 LiveNest 的产品选择，并非对参考产品的测量。

- 分组标题统一为 15px / 650 / 20px 行高、深色文字，浅灰背景 #e8edf4、上下内距 8px，形成桌面 36px、窄屏至少 44px 高的平直标题栏；组前 24px、展开后的子项上距 8px。同类分组共用一条规则。
- 发布区分组为「发布任务」「配置与账号」；直播的「直播设备」、管理员的「工作空间」以及发布策略的「管理员」同样沿用分组组件。标题是整行按钮，默认全部展开；右侧箭头向下表示展开、向右表示收起，支持点击及 Enter / Space。
- 网页导航项统一为 15px 正文色；顶部当前模块使用加粗文字和蓝色图标，具体页面继续使用浅蓝底和蓝字，避免两层相同的选中样式。
- 子项整体向右缩进 20px，选中底色和焦点轮廓随子项移动，菜单项间距为 4px。收起时仅隐藏该组导航项，退出焦点与读屏顺序，当前页面、草稿及上传保持挂载。
- 分组状态由当前账号的 `SidebarGroupsProvider` 在内存保存，放在手机抽屉及导航 Portal 外；切换模块、调整窗口尺寸、关闭并重开抽屉不重置选择。刷新、退出或切换账号恢复默认展开，不写浏览器持久存储。
- 顶部模块分隔线、左下角设置与账号、键盘焦点和窄屏抽屉保留。草稿、滚动、上传、权限和授权流程没有变更。
