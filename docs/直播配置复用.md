# 三步开播与直播配置包

## 使用流程

1. **素材选择**：选择循环视频、背景音乐，不显示预览或发布选项。
2. **完善内容**：选择配置包；编辑标题、说明、封面并可生成文案；完整配置默认收起，展开后可编辑全部本场素材、文案、封面与直播规则。
3. **开播**：显示最终预览与参数摘要，检查条件并开播。可返回修改，保留草稿。

完整配置不是另一份表单状态。`useInstance.selection` 是所有输入、最终预览及 `/api/control` 请求的共同来源。重复字段只使用不同 DOM 标识，直接同步。上传封面、生成文案期间锁定配置；退出第三步卸载预览。工作区切换保留草稿、步骤和上传任务。

## 默认设置与配置包

「设置 → 直播默认」按登录账号管理公开范围、儿童选项、视频原声。首次默认公开、不面向儿童、原声关闭；只初始化没有既存数据的新草稿，不覆盖旧草稿或运行场次。

「设置 → 直播配置包」按设备、实例与频道管理规则：公开范围、儿童选项、视频原声、播放列表。支持另存为、更新、重命名、删除。工作台第二步只选择套用；明确确认后只更新规则，保留素材、标题、说明和封面。撤销也保留套用之后编辑的文案。手动调整形成本场最终配置，不自动写回配置包。

设置中编辑包只刷新工作台的列表，不自动套用。初始化时旧草稿与运行场次优先；新草稿读取默认值，之后显式套用和手动编辑依操作顺序生效。

旧版本包仍可读取，无批量迁移；套用时只提取规则。新保存或更新规则时清空包中的文案、素材引用和封面引用，原素材文件与授权不删除。重命名保持原快照。每目标最多 50 套，名称最长 60 字且不重复。AI 观众互动暂不纳入配置包，独立运行控制默认收起，直播中展开。

## 数据边界

- 配置包接口 `/api/broadcast-profiles` 按设备所有者、实例、已确认频道隔离；管理员协助使用设备所有者范围并记录审计，保存与删除检查修订号。
- `/api/broadcast-defaults` 按当前鉴权账号隔离，在数据目录下 `broadcast-defaults/<账号哈希>/defaults.json` 原子保存。严格 schema、同源校验、文件事务与修订号防止跨账号或并发覆盖。读取失败不会伪装成默认成功。不提供管理员代改其他客户默认值的入口。
- 不保存 API Key、OAuth、OBS 连接或机器路径，不发送开播命令，不改变 Agent 协议。

## 设计参考与验证

参考 [PatternFly Wizard](https://www.patternfly.org/components/wizard/design-guidelines/) 的明确步骤及统一底部操作和 [Carbon Forms](https://www.carbondesignsystem.com/building-blocks/core/patterns/forms) 的多步表单组织。准备阶段采用单列，预览只在第三步出现；保留现有品牌与控件。

`tests/broadcast-options.test.ts` 检查规则套用/撤销、真实默认值存储隔离、并发与输入保护。原配置包 API 集成继续覆盖真实文件 CRUD 与权限。`tests/broadcast-profiles-ui.smoke.mjs` 验证三步、双向同步、设置管理、套用及最终请求；使用隔离预览存储，设备和控制为合成数据。当前界面截图见 `screenshots/live-profiles/`，旧日期截图是历史材料。

最终 `npm run verify` 通过：110 个测试文件、1048 项测试、8 项部署测试、类型检查、Lint、Next 与 Agent 构建。三步浏览器验收通过，包括新草稿默认值及 1440/390/320px 布局；工作区连续性和视频发布回归也通过。工作区/发布回归早于最后视觉整理与默认值初始化竞态修复，最终三步验收已重跑。

此次仅更新原 PR 和 localhost，未合并、部署、升级安装版或执行真实 OBS、OAuth、YouTube、付费 AI 验收。
