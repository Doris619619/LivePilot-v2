# 直播聊天整改

## 用户行为

本场编排与直播配置包使用同一互动编辑器。八个人设为电台搭子、深夜守夜人、俏皮捧场王、冷面吐槽役、猫猫值班员、太空电台员、文艺拾句人、极简酷搭子，另有自定义。选择后展示双语风格示例；示例不是实测记录。可调回复长短、幽默、表情与主动提问。风格与接话模式分离，默认尽量回应，有自然参与和被叫才回可选。

频道背景必须明确填写，提供「AI 音乐，未命名」便捷填入。不能把用户当前频道的事实自动推广到其他频道。无需认歌，也不编造曲名、作者或版权。

运行面板的「人设与试聊」可在直播期间编辑并保存。试聊使用当前草稿，保留最近 16 条结果，同一草稿最多携带八轮对话，结果区分回复、澄清与跳过。更改草稿保留预览，以人设和设置快照标注结果；「用当前人设比较这句」直接重新回答原留言，不带上下文。失败保留输入。试聊需要在线 Agent 和 AI 额度，但无需直播或 YouTube 发送授权；它不会发送 YouTube 聊天。

## 设计取舍

- 借鉴 [StreamChat AI](https://www.streamchat.ai/faq) 的独立接话模式与人设预览，但保留本项目尽量回应的默认目标，不复制其平台权限与记忆套餐。
- 借鉴 [StreamElements](https://docs.streamelements.com/chatbot/commands/default/song) 的事实来自系统的原则；本项目对未命名 AI 音乐使用明确背景，不依赖现成歌曲数据库。
- 借鉴 [Streamlabs](https://streamlabs.com/content-hub/post/cloudbot-101-custom-commands-and-variables-part-two) 的限频思想；不通过随机错字或虚假真人身份制造自然感。
- 保留 Agent 执行：Cloud 只鉴权、投递和状态交付。旧配置兼容，新参数与试聊通过 chatConversation 能力门禁。只更新网站不能替换设备上的生成器。
- 正常跳过是业务决定；与模型错误、发送失败、未知发送结果分开。最多合并相邻四条同人留言，生成后到达的新留言不合并。
- 确定性防护负责 @ 归一化、明确语言错配、重复回复、被叫模式及无意义标点；模型负责语义与人设。不能宣称所有歧义和多语言都已确定解决。

## 真实模型离线评估

2026-10-18 使用真实生成器与配置模型，对合成观众做两轮评估，每轮 23 个场景。没有连接 YouTube 聊天、开停播、OAuth 或真实观众。

第一轮暴露强制首条欢迎把人设压成客套话、英文弯引号绕过语言检查、模型重复加称呼。修正后第二轮样本：

| 输入/人设 | 真实结果（省略统一称呼） |
| --- | --- |
| 好好听呀 / 电台搭子 | 那就多待一会儿～ |
| 好好听呀 / 俏皮捧场王 | 耳朵投了赞成票 🎶 |
| 好好听呀 / 冷面吐槽役 | 今天耳朵没白上班。 |
| 好好听呀 / 猫猫值班员 | 批准再听一会儿 🐾 |
| 好好听呀 / 极简酷搭子 | 有品。 |
| I’m still doing homework / 深夜守夜人 | Take your time with it. |
| I’m still doing homework / 太空电台员 | Homework orbit noted. The signal's here when you need a break. |
| 连续中文后 I like it | Glad you're enjoying it 🎶 |
| 这是什么歌曲呀 | 这首还没有名字，是直播间的 AI 生成音乐～ |
| what is 谈何 | clarify：Was that a typo? I'm not sure what 谈何 means here. |
| asdfghjkl | skip，不发送 |
| 你是人吗 | 不是哦，我是直播间的 AI 助手。 |

边界：部分夸赞样本直接采用了人设示例，因此不能据此证明长期变化丰富；另有未在示例中出现的英文作业留言用于检查迁移。极简人设的英文输出仍可能比目标长；有限样本不等于稳定成功率。明确词义问题仍可回答，不能把所有生词都判断成笔误。

复现脚本 `scripts/evaluate-live-chat.ts` 需显式运行，会消耗模型额度；先用 esbuild 打包到忽略目录，再以已有环境运行。仅输出合成输入、公开决策和安全错误标记，不记录 Key 或原始上游异常。原始本机样本位于 `.data/chat-evaluation/results.json`。

## 验证与部署边界

自动验证覆盖模型跳过、语言纠正上限、重复回复、前缀、合并消息、旧配置、试聊并发与 API 能力门禁。浏览器脚本 `tests/chat-conversation-ui.smoke.mjs` 使用全部模拟 API，与真实模型离线评估分开。

尚未制作新版安装器、未部署 Cloud/Agent、未验证真实 YouTube 观众收发。发布时先更新 Cloud 再升级 Agent，继续保留原频道授权、实例和配置。
