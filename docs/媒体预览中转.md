# 媒体预览中转

## 数据流

浏览器 `POST /api/media-preview` 提交设备、实例、可选独立账号／频道及素材标识和版本。Cloud 验证登录、设备归属、在线状态与 `media-preview-v1` 能力，为这次登录创建十五分钟会话。后续请求只接收会话 ID 和动作，不允许替换目标。

Agent 通过既有固定 HTTPS 控制端地址主动 `GET /api/agent/media-preview/poll`，每次最多取得四个短命令，再向 `/api/agent/media-preview/{requestId}` POST 元信息 JSON 或原始二进制分片。此通道不进入持久任务、Worker、心跳快照或任务日志。生产不接受任意 URL、入站 Agent 端口或 Cloud FFmpeg；显式 loopback HTTP 仅用于本地测试。

浏览器 `GET/HEAD /api/media-preview?id=…&part=video|music|cover|final` 支持单区间、开放末尾和 suffix Range，206 包含准确 Content-Range；非法范围返回416。Cloud 每次向 Agent 读取最多 1 MiB，按浏览器背压逐片交付；断开不再索取后续数据。JSON 上限64 KiB，每台设备最多12个待请求、全局64个，邮箱25秒过期。Agent 每次轮询最长15秒。

## 身份与文件

- 浏览器会话绑定登录 Cookie 摘要、设备、实例、账号、频道与素材版本，最多每次登录六个、全局128个。退出、换账号、账号清理、设备撤销、过期均不能复用读取 URL；关闭会话只撤销原绑定能力，并尽力取消设备工作。
- 每个媒体响应和每一分片再次校验登录与设备归属；设备回复后再次校验授权。Agent 每次读取也验证绑定目标和所有源文件身份。
- 浏览器不能提交实际路径。Agent 使用现有固定 Inbox 包解析与实例媒体解析，拒绝目录逃逸和链接；包版本和文件大小、mtime、ctime、inode共同绑定。读取前后验证打开句柄，文件变化撤销会话。
- 响应只通过白名单元信息；路径、令牌、原始 FFmpeg stderr、媒体字节不进入 JSON 状态、持久任务或日志。会话 ID 不是独立授权凭据，仍需当前登录。

## 检查与正式发布复用

`open` 创建快速检查；`status` 获取检查事实；`check` 执行第一路视频／音频全程解码；`cancel` 停止；`prepare` 仅对发布包调用 PublishingRunner 的预处理入口。实际生成继续使用 `preparePackageUpload`、版本目录、跨进程生成锁、`validatePreparedUpload` 和 SHA-256。预览没有生成发布任务、扣上传配额或构造 YouTube API。

单台 Agent 同时仅一个检查／准备操作，避免与正在运行的发布任务抢占资源。直播开始优先取消检查；FFmpeg 使用有限线程并可取消。关闭、过期、退出 Agent 时回收当前工作。媒体读取不要求检查成功，检查异常也不新增发布门槛。

退出状态在轮询返回、异步授权和素材解析后再次校验，迟到请求不能重新启动检查。视频流未提供有效时长时，检查使用容器的有效时长；两者都不可用才提示无法确认时长。

浏览器在打开请求期间关闭时，Cloud 在有界设备回执之后撤销会话，避免丢失尚未返回浏览器的会话 ID；打开失败也尽力取消设备工作。

## 部署约束

当前 Cloud 会话与中转邮箱只在同一个 Node 进程内，适用于仓库现有单实例部署。重启会失效，浏览器重新打开即可恢复。**不能在没有统一中转路由的情况下启用多进程／多副本负载均衡**：浏览器与对应 Agent 请求必须进入同一个进程；当前未提供分布式媒体队列或共享媒体缓存。

升级通过会话能力协商启用；旧 Cloud 用 400 拒绝新增能力时，新 Agent 用既有能力列表重试一次，不开启预览通道；认证或网络错误不作降级。旧 Agent 连接新页面仍可进行原发布与直播，预览提示升级。检查需要 Agent 本机 FFmpeg 和 ffprobe，优先读取数据根 tools 目录，再查询 PATH。

`tests/media-preview.test.ts` 覆盖 Range、文件变化、会话撤销、工具缺失、限流和中转隔离；`tests/media-preview-access.test.ts` 覆盖真实登录与账号存储边界；`tests/media-preview.integration.mjs` 覆盖独立 Agent 的真实 HTTP、FFmpeg、浏览器播放和成片缓存。所有平台身份均为隔离测试数据，没有真实 OAuth 或直播验收。
