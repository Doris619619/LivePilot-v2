# 发布前预览

前端已由用户确认，正式入口现接入 Agent 素材读取和检查。预览不创建上传任务、不调用 YouTube 发布接口、不修改 OBS，也不新增发布强制门槛。

## 在哪里预览

- **普通视频**：准备素材时可从发布包打开；确认计划时点击视频数量旁的“预览视频”，直接读取已有标题、频道、封面策略、视频和音乐，可切换计划中的视频。入口与数量同组，窄屏时频道信息另起一行。编辑弹窗默认展开预览，但不自动播放；可手动收起，重新打开编辑弹窗时恢复展开。未保存标题即时联动，无需再次填写内容配置。
- **直播**：预览跟随当前实例的素材、原声开关与直播详情，桌面并排，手机通过全屏弹窗打开。切换设备、账号、素材或关闭弹窗时卸载播放器并撤销会话；切换到手机布局不会留下隐藏的桌面播放器。
- **独立 `/preview`**：保留本地文件与合成样例，用于界面体验。这里的示例检测标识不会变成真实检测结果，也不会调用业务接口。

## 看、听与检查

点击画面或播放按钮才启动声音；支持暂停、拖动、音量、静音、全屏、当前时间和总时长。原视频播放原声；普通视频的发布效果用背景音乐替换原声，短音乐循环、长音乐截断，时长跟随视频。直播视频与音乐分别循环，原声遵循当前开关；拖动时重新对齐音乐。

打开设备素材自动读取 FFprobe 元信息，使用 FFmpeg 抽查开头、中间和末尾各最多三秒，重叠区间合并。显示实际时长、分辨率、音轨和检查范围；疑似静音只代表检查范围，不能据此宣称整段无声。播放器自身静音单独提示。

“完整检查”全程解码第一路视频和音频，显示真实媒体时间进度并支持取消；“检查最终成片”由 Agent 的 PublishingRunner 提前准备正式上传文件，沿用版本缓存、生成锁及哈希校验。生成成功后可以播放最终文件；后续发布仍重验源文件和缓存，不盲目复用。

检查和合成在同一设备串行，设备正在直播或发布时提示稍后再试；开播优先并中止当前检查。无 FFmpeg/ffprobe 时显示工具不可用，不误判损坏。网络中断、浏览器不支持编码、解码失败分别提示；文件替换后旧预览失效，需重新打开。

封面／标题按手机和桌面 YouTube 信息流示意展示，保持图片比例、截断长标题并允许查看全文；不伪造观看量。无自定义封面时显示自动选择、实际封面待定。有真实直播场次才提供官方播放器和观看／Studio 链接；私密场次转官方入口，未有场次时不自动测试推流。嵌入可用性与实际平台输出仍须真实频道验收。

## 本地验收

```powershell
npm run verify
npm run desktop:build
node tests/media-preview.integration.mjs
```

隔离集成脚本使用实际 HTTP 路由、独立 Agent 子进程、真实 FFmpeg 和合成文件；账号/频道身份为测试数据。验证原视频、无音轨、静音、损坏、Range、完整解码、正式计划预览组件、最终文件哈希与缓存复用。报告及截图在 `.data/media-preview-integration/`。

运行 `node tests/media-preview.integration.mjs --serve` 可在 `http://127.0.0.1:3031` 体验正式计划预览组件与真实设备读取链路；仅监听本机，使用独立数据目录和测试身份，关闭进程后会话失效。不会运行 Agent 的发布或直播任务循环。

原有前端演示仍可执行 `npm run preview:local` 后打开 `http://127.0.0.1:3021/preview`；其工作台里的模拟设备没有新能力时会显示升级提示。运行 `node tests/media-preview-ui.smoke.mjs` 验证本地文件试听、混音、释放资源、封面与桌面／手机布局。样例来源与重建命令：本仓库原创山景 SVG、12 秒合成视频、4 秒音乐；`node scripts/preview/generate-media.mjs`。

## 部署与限制

Cloud 与 Agent 都需升级；旧 Agent 显示升级提示，原有发布和直播功能保留。Cloud 使用单进程有界内存中转，不存完整媒体、不运行 FFmpeg。接口、权限与部署约束见 [媒体预览中转](媒体预览中转.md)。

本地文件与合成测试不等于真实客户设备、OAuth、YouTube 上传、扬声器听感或真实接收画面验收。最终成片一致性验证的是准备文件与正式上传缓存的哈希，未进行真实 YouTube 上传。
