# 发布前预览（前端体验版）

当前交付只包含前端，先由用户确认界面，再实现媒体读取和检查后端。没有新增 Agent、Cloud API、OBS 监看、YouTube 请求或发布门槛。

## 体验入口

完成 `npm run build` 和 `npm run desktop:renderer` 后，运行现有的 `npm run preview:local`，访问 `http://127.0.0.1:3021/preview`。该入口使用项目既有的隔离预览服务。独立 `/preview` 页面无业务 API 调用，也可在常规开发服务对应地址查看。

- 左侧修改标题、频道、直播／视频模式和示例，右侧实时预览；手机打开全屏预览，关闭后保留外部编辑表单。
- 直播配置右侧、发布包列表和确认计划编辑弹窗也提供相同预览组件。设备文件目前不能直接读取，需选择本地文件试听；封面已在设备上但无浏览器 URL 时显示“设备图片读取待接入”。
- 文件通过浏览器 Object URL 播放，不上传到任何服务。本地选择只影响试听，不更改实际发布包或直播素材。更换文件、切换模式或关闭预览会停止旧播放器并释放资源。
- 原视频播放自身声音；发布效果在普通视频模式使用背景音乐替换原声，短音乐循环、长音乐随视频结束停止；直播模式视频和音乐各自循环，原声开关参与试听。点击／轻触视频画面即可暂停和继续，聚焦画面后 Space／Enter 同样可用；视频和背景音乐一起暂停。音量、静音、进度和全屏控件独立操作，不触发画面点击。
- 时长和分辨率来自浏览器实际读取的元信息。有声、无音轨、采样疑似静音提示来自明确标注的**示例检测结果**；本地文件显示“音轨尚未检测”。播放器静音独立提示。浏览器播放失败不直接等同于文件损坏。
- “预览内容”用于素材试听；“预览封面／标题”依据用户提供的 YouTube 首页截图，展示手机单列、桌面三列信息流：顶部栏、分类栏、频道头像、两行标题和相邻卡片占位。桌面卡片保持可读尺寸，窄容器可横向滚动或点击“展开预览”。完整标题仍可查看，封面保持比例；不虚构播放量、观众数或推荐内容。未知时长不画平台时长角标，直播角标只来自真实状态；预约时间仅在提供实际时间时展示。导航和相邻视频只是静态示意，不冒充 YouTube 页面或可点击的平台功能。
- 页面只保留一处体验版提示，删除重复标题和操作说明；时长与循环状态合并展示，预计成片时长仅在视频发布效果下展示。普通播放器不再重复显示来源角标，全屏时仍显示来源。
- 声音状态、异常提示与示例检测标识直接展示；完整检查和最终成片检查暂不可用，能力边界集中到折叠的“预览说明”。不显示不可用的检查按钮或空的 YouTube 接收画面入口，没有模拟检测进度或伪造检测通过。

## 合成测试素材

`public/preview/` 包含本仓库原创 SVG 山景，以及 12 秒 H.264 有声、无音轨、静音音轨视频，4 秒和弦音频和一个故意无效的播放失败文件。声音为低音量合成测试音；画面为静态测试图。这些素材不来自客户文件。

重建：安装 FFmpeg 后运行 `node scripts/preview/generate-media.mjs`，可用 `FFMPEG_PATH` 指定可执行文件。脚本只写测试资源和 `.data/preview-media/`，不属于运行时媒体处理服务。

浏览器回归：先启动上述隔离预览，再运行 `node tests/media-preview-ui.smoke.mjs`。报告和截图位于 `.data/media-preview-ui/`。真实扬声器听感、完整文件解码和真实平台输出不由这些前端测试证明。

## 待确认后实现

Agent 元信息／快检／完整解码检查、受限 Range 媒体中转、设备权限及会话过期、最终成片准备与 PublishingRunner 缓存复用均尚未实现。未来 Agent 仍只主动出站连接 Cloud；Cloud 不执行 FFmpeg、不保存完整媒体，预览字节不得进入任务日志和 JSON 快照。

## 首版验证（2026-10-13）

- `npm run verify` 通过：103 个测试文件／1016 项测试、8 项部署检查、类型检查、零告警 ESLint、Web 和 Agent 构建。
- `npm run desktop:build` 通过：本地 Windows NSIS 打包与打包资源检查；未安装或发布该安装包。
- `node tests/media-preview-ui.smoke.mjs` 通过 6 组浏览器场景：真实合成文件播放／暂停、静音提示、原声开关、发布音乐替换与定位、视频结束停止音乐、示例异常提示、本地文件元信息、Object URL 释放、封面标题联动、手机全屏／Escape／焦点返回。确认独立验收页面零业务 API 请求、零未捕获浏览器错误。
- 现有 `tests/publishing-ui.smoke.mjs`（100 个模拟发布包／四步流程）及 `tests/live-chat-ui.smoke.mjs`（直播工作台桌面／手机）通过。所有账号和业务接口为隔离模拟，没有真实上传、OAuth 或开播。
- 桌面、手机和两种封面卡片截图位于 `.data/media-preview-ui/`。浏览器回归会禁用截图瞬间的入场动画，避免截图停在淡入过程。
- 验证期间一次复跑因 C 盘 `ENOSPC` 导致临时进程副本复制失败，并出现测试清理超时；仅对验证进程改用 D 盘专用临时目录后，完整验证通过。未修改系统临时目录设置。

前端验收仍等待用户确认。全程解码／采样检测、真实设备读取、最终上传文件一致性和 YouTube 接收画面不在当前实现或验收结论内。
