# 前端细节复审

## 复审原因

上一轮把 API Key 和互动偏好集中到了设置，但没有充分检查窗口本身的信息密度。用户截图中的对象重复、用途重复、嵌套卡片、分散按钮和长滚动页确实仍然存在。功能回归通过不能证明这块 UI 已经精简到位，本轮补充实际窗口尺寸和状态组合的验收。

继续沿用 Impeccable 的 Operate / distill / craft floor，保留现有功能、蓝色品牌、实例隔离和原配置。不调整真实授权，不执行开播、上传、模型调用或客户账号写入。

## 检查范围与保留项

本轮在上一轮全表面检查基础上，重新核对下列入口及其交互细节。源码检查不冒充真实业务验收；未修改的部分也列出保留理由。

| 区域 | 核对细节 | 处理 |
| --- | --- | --- |
| 登录、账户 | 加载、失败、密码输入、当前身份、切换后草稿隔离、退出 | 修复菜单反馈；保留身份验证与整页切换 |
| 设置、互动偏好、显示 | 作用对象、未选 / 空 / 离线 / 未配置 / 已配置 / 更换 / 保存中 / 失败，关闭与焦点 | 本轮重点重做；保存锁、旧响应隔离、密钥不回显仍保留 |
| 直播四步 | 标题说明、生成/撤销、素材、公开范围、儿童内容、播放列表、封面、开始与结束 | 补充表单语义；草稿、阻塞条件和异常恢复不减弱 |
| 互动运行面板 | 状态、开关、频率、恢复、记录、过期和旧客户端 | 修正未知状态及产品用语；历史和独立服务说明保留 |
| 设备配对与移除 | 空状态入口、目标名称、邀请期限、保存中关闭、失败与回到目标 | 保留真实影响说明，避免精简后误以为移除会停止直播 |
| 上传与恢复 | 文件限制、失败保留选择、未完成上传、查询与取消 | 补充读屏关联；不自动重试写操作 |
| 发布素材与向导 | 检测、无批次、异常包、分页、暂不发布、返回草稿 | 保留明确步骤与文件位置提示 |
| 发布配置与策略 | 模板、AI、封面、儿童内容、列表读取、保存中输入与返回 | 修正保存锁与空结果 |
| 排期、计划与执行 | 时区、星期、多时段、日期、未保存改动、确认、改期、取消、归档 | 保留用户确认和远端结果核对，不折叠发布后果 |
| 我的发布与历史 | 频道分组、过滤、分页、空结果、过期状态 | 保留现有分组与历史辨认，交由发布浏览器套件回归 |
| 素材预览 | 原视频/发布效果、封面标题、播放控制、声音检查、失败、全屏和释放 | 删除旧空状态文案；保留抽样与真实输出的区别 |
| 管理员 | 筛选、无客户/无设备、归属、创建与重置、时区 | 修正分配空状态与时区重复说明 |
| 桌面客户端 | 设备配置、本机 OBS、手动连接、更新、目录、账户、帮助 | 本轮不改变本地控制协议；重新构建共享组件并回归模拟桥 |
| 下载 | 版本、历史、加载失败、重试、安装与配置保留说明 | 保留版本与恢复信息，未触发下载或安装 |
| 条款、隐私、帮助 | 入口名称、删除后果、授权边界、技术说明 | 仅修正过时路径，不删法律或高影响说明 |
| 共享控件 | 对话框、抽屉、页签、折叠、焦点返回、键盘、长文与窄屏 | 简单表单可隐藏视觉介绍，读屏描述仍存在 |
