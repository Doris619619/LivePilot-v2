# 上传界面与网站下载

## 用户流程

网页上传按“文件 → 进度 → 操作”展示；传输中只显示暂停，完成后可上传下一个。历史上传放入“找回未完成的上传”，仍可查询、恢复和取消；传输中禁用恢复操作，避免覆盖当前任务。空素材处的“添加视频／音乐”自动打开上传区并选中对应 OBS，有进行中任务时保留原目标与进度并解释原因。

登录页和工作台都有 Windows 客户端入口，未登录也可打开 `/download`。页面使用蓝白产品展示、真实工作台的合成示例截图、下载按钮、三步指南和安装帮助；支持小屏、键盘与减少动画偏好。

一台 Windows 电脑可在客户端“本机 OBS”中增加多个独立实例；每个实例有独立端口、配置、素材和频道。增加实例前必须确认设备空闲并取得维护许可，不使用共享旧 OBS 替代独立实例。

## 部署契约

Nginx HTTPS 模板将 `/downloads/` 映射到独立的 `/var/www/livenest-downloads/`，不指向业务数据目录。仅 GET/HEAD，禁用目录列表和符号链接，支持 Range 续传。只放公开安装资产，目录 755、文件 644、root 所有；不复制私有环境或账户数据。

先在临时目录核对文件哈希、大小和清单，再原子安装到版本目录。修改现有 Nginx 时保留其他 server、TLS 和代理设置，备份后执行 `nginx -t`，通过才 reload；失败恢复原配置。网页在独立发行目录构建，备份并切换程序。回退仅切换程序/代理配置，不回滚业务数据。

上线后检查公开下载页、下载 GET/HEAD/Range、完整响应哈希、缺失文件、目录列表和 POST 拒绝；业务 API 继续要求登录，并确认 Agent 心跳恢复。
