# 前端 UX 精简审计

## 目标与方法

保留直播、未来视频发布、账号授权、素材预览、配置管理及故障恢复等现有能力。用户明确的痛点是重复说明和不顺畅的操作逻辑。本次沿用 LiveNest 的蓝色、中性色和现有组件，以任务完成为主，不重新设计品牌。

使用已安装的 Impeccable：独立设计评审 A 与技术审计 B 分别检查源码和独立浏览器标签；A 完成后才汇总 B。默认浏览器预览为合成设备与会话，不连接真实 OBS、YouTube 或模型服务。没有把缺少暗色模式、可横向滚动的数据表或预览夹具能力限制误报为生产缺陷。

## 基线诊断

| 启发式 | 分数（0–4） | 发现 |
| --- | --- | --- |
| 状态可见性 | 3 | 在线、过期和未确认状态准确，但重复摘要较多 |
| 用户语言 | 3 | 主任务清楚，恢复提示仍暴露 Agent 术语 |
| 用户控制 | 3 | 返回、撤销、草稿保留完整 |
| 一致性 | 2 | 网页与客户端的设置、账户位置不同 |
| 错误预防 | 3 | 开播前置条件与发布确认应保留 |
| 识别而非记忆 | 3 | 四步流程有效，入口和标题重复 |
| 效率 | 2 | 首屏空间用于容器和摘要，核心编辑区域偏低 |
| 简约 | 2 | 多层卡片、完成标签、装饰和说明叠加 |
| 错误恢复 | 3 | 版本不足时只有重读，缺少更新路径 |
| 帮助 | 3 | 帮助齐全，但应按需查看 |
| 合计 | **27/40** | 改造前基线，不是改造后的自评分 |

技术基线：无障碍 3/4、性能 3/4、主题系统 2/4、响应式 3/4、实现完整性 3/4（14/20，检测器复核前暂定）。未做真实设备性能基准，不将静态代码检查写成性能提升。

主要影响三类用户：日常多频道操作员需要减少翻页和辨认层级；首次接入用户需要在空状态直接配对；键盘用户需要读出时区当前值并快速离开候选列表。

## 全表面审计与实施

| 表面 | 问题与处理 | 保留的业务边界 |
| --- | --- | --- |
| 全局导航 | 移除网页顶栏重复工作区链接和 Studio 标签；管理员入口集中到侧栏；删除重复品牌页脚 | 账户切换、退出、权限和原路由保留 |
| 工作台 | 压缩标题、设备摘要和实例标题行；移除编辑器内框及“直播设置”重复标题；改为单层实例外框 | 每个实例仍独立持有草稿、频道与操作目标 |
| 开播控制 | 待机不显示结束，直播中不显示开始；非直播异常仍保留开始/重试与可用结束入口 | 未确认场次、推流中和异常状态继续沿用 canStopBroadcast；禁用条件不放宽 |
| 文案生成 | 顶部入口常驻，以次级按钮呈现；生成后的反馈缩短 | 保留 API 设置快捷入口、生成失败保留文案、撤销 |
| 设备配对 | 侧栏和空状态打开同一对话框；不再把表单挤在窄侧栏内 | 状态由工作台持有，关闭/切换尺寸保留草稿；提交期间锁定关闭；不存储邀请 |
| 素材预览 | 检查范围和采样时间移入详情；完整/抽样状态仍直接显示；更新错误增加客户端设置和下载路径 | 疑似静音、无音轨、失败及忙碌不隐藏；不把抽样宣称为完整检查 |
| 视频发布 | “设置”分组改为“发布管理”；已有账号时将新增集中在账号管理；保留从工作流直达管理 | 发布向导、未来排期、重复素材核对、历史、取消和归档均保留 |
| 时区选择 | 读屏名称包含当前时区；选项从 Tab 顺序移除，搜索框通过方向键与 Enter 选择 | 搜索不自动保存，Escape 保留原值，Tab 可直接离开 |
| 管理员 | 六张大指标压成紧凑筛选条，去掉重复工作台链接 | 所有筛选、客户权限、归属、审计操作和表格横向滚动保留 |
| 桌面 OBS | 就绪实例默认收起五步配置；未完成实例自动展开；完成步骤按需查看；状态区减少嵌套框 | 检查、重新启动、频道、素材、高级配置和问题恢复均保留 |
| 桌面设置与账户 | 设置和账户固定左下角；顶栏更新提示打开后再执行；统一 SVG 品牌 | 原本地会话、配对、目录、授权和更新协议不变 |
| 登录 | 移除重复内层徽标，标题直接表达登录；说明账号由管理员提供 | 无新增注册流程；密码、自动填充、已登录账户保留 |
| 下载 | 标题改为明确的客户端下载；去掉透视截图、装饰窗口条、巨大品牌字与入场动画 | 版本、安装包、校验清单、历史版本和安装指引保留 |
| 共享视觉与可访问性 | 共享成功绿覆盖桌面漂移色；提升生成区和预览控件尺寸；取消页面/页签入场动画及泛化极短动画覆盖 | 保留焦点、真实状态、进度、必要分隔和组件级减少动画设置 |
| API/互动/显示设置 | 复查既有迁移结构，保持低频配置集中；本次只统一导航和外观 | 不新增密钥层级，不返回密钥，不改原配置位置 |
| 隐私/条款/帮助 | 审计入口与层级，保留必要说明和法律原文 | 不因“精简”删除授权、删除数据或高影响操作说明 |
| 独立预览页 | 修正 LivePilot 品牌为 LiveNest | 保留“演示/示例”标记，避免把本地素材当真实设备结果 |

## 发布与限制

改动在 PR #39 审阅，尚未合并、部署或打包发行。0.1.14 安装版与线上站点不会自动包含此变更。没有迁移或重置用户配置与授权。

后续值得独立处理的是历史 CSS 多处定义的进一步收敛，以及真实设备/触屏上的全流程验收。本次不把没有测量的性能收益或模拟预览成功写成真实业务成功。
