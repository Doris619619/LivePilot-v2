# 界面与内置成员

## 界面规则

参照浅色协作工作台：浅灰设备导航、白色主工作区、细分隔线和蓝色主操作。主区只保留“直播工作台”与上传入口，删除面包屑、描述副标题、统计小字、心跳、运行说明和重复设备路径。

实例行以频道、状态、操作三列对齐。主标题优先显示已连接的 YouTube 频道名，OBS A / OBS B 等配置名仅作辅助标识；未获取过频道名时回退到配置名；已有授权失效时保留绑定名并显示连接异常。标题下始终显示电脑名称、OBS 配置名与实例 ID。离线时保留上次获取的名称并显示过期提示。上传目标同步显示频道名、设备及实例标识，频道改名或重新授权后随状态刷新更新；请求仍按设备 ID + 实例 ID 路由，同名频道不会串台。默认展开 1 设备与频道、2 音视频编排、3 直播控制、4 运行状态；桌面四步横排在同一行，1000px 及以下按顺序单列以保持文字和操作尺寸；收起后可直接操作直播。开停播按钮始终只保留一组。步骤 1 展示 OBS 配置名、频道名和各自连接状态，并提供已绑定频道链接；授权频道的公开 ID 随状态返回，兼容未提供该字段的旧 Agent。隐私范围、ID、刷新与异常恢复收进“连接与诊断”。错误、离线、结果待核对和开播阻塞原因保持可见，避免为了简洁隐藏风险。

正文/表单 16px，实例名 18px，页标题 24px，辅助信息不低于 14px。统一使用自托管 Noto Sans SC 衍生字体，变体字重 400/500/600，登录和控制台使用同一套中英文字形。来源、许可、字符覆盖与生成方式见 [字体说明](../src/app/fonts/README.md)。

手机端按单列排布；操作至少 44px，支持键盘展开、焦点提示和减少动画。表单不依赖 input 显式 type 获得基础样式。成功获取空列表才显示接入提示；失败显示错误与重试；未具备开播条件显示“待配置”。

## 内置成员

服务端 scrypt 凭据定义位于 src/server/builtin-member.json，登录与管理命令只追加缺失的 Do 成员。已有成员、密码重置、禁用与会话撤销保持有效。登录表单、HTTP 接口、成员 CLI 和 Agent task actor 均接受区分大小写的 2–32 位字母、数字、下划线。create/reset 的密码强度要求维持原有 12–256 位；用户指定的内置初始密码是单独的初始化凭据。

升级应同时更新云端与 Agent；旧 Agent 的 actor 校验不接受 Do。此分支不重写生产账号文件、不变更既有 OAuth、OBS 或频道配置。上线后首次登录才会在部署自己的账号存储中创建内置成员。

## 验收

以隔离存储验证内置登录、大小写、错误密码、已有同名账号保留、禁用与会话撤销、Agent 协议兼容。界面需通过生产构建浏览器检查登录、上传、实例展开、错误恢复、键盘操作和窄屏溢出。实际执行结果记录在 [VALIDATION.md](VALIDATION.md)。不以本地验收代替生产部署或真实开停播验收。

设备名称来自配对时保存的名称，OBS 名称来自所属 Agent 的实例配置，频道名称来自真实授权状态；无设备时显示接入空态。预览脚本使用明确标注的“示例电脑 / 示例频道”，这些测试数据不进入应用代码或线上兜底。

推流时长与状态请求解耦：保留每 5 秒状态轮询，页面每秒按浏览器单调时钟推进，并由新 OBS 快照校准。重复或迟到的 Agent 快照不回退计时；新场次、OBS 重启以新时长重新起算。停止或重连时保持已确认值；时长未知、请求失败、设备离线或连续 20 秒无新快照时显示“—”，不把估算当成推流状态。收起与展开区域共享同一个计时基准。
