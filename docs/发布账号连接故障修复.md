# 发布账号连接故障修复

## 故障与原因

添加账号分为创建账号记录和连接 YouTube 频道两步。创建后的账号立即成为当前选择；旧实现按操作开始时的页面和账号保存错误，因此第二步失败时，错误仍归属原选择，被新账号页面隐藏。设备离线时也允许用户连续创建账号，容易出现多个“未连接”账号。用户删除后，离线设备无法回报清理完成，旧账号继续显示“等待设备清理”。

## 修复行为

- 连接错误按请求的账号 ID 保存。账号管理页在对应账号旁显示错误；发布视频页显示当前账号的错误和“重试连接频道”。创建成功后连接失败不会再丢失提示。
- 重试只连接原账号，不重复创建。切换账号不串用错误；后台轮询与显式刷新保留连接错误，重新连接时清除该账号的旧错误。
- 仅设备状态明确为离线时禁用添加、连接和重试，并提示打开所选电脑的 LiveNest。状态未知保留操作入口，由服务端核对；设备上线后刷新恢复按钮。
- Cloud、OAuth、账号清理与授权协议保持原有行为。清理中的账号仍不能连接，只有所属 Agent 确认撤销与本机清理后才完成删除。此修复不强制清除账号、不修改既有授权。

## 验证记录

- `node tests/publishing-account-connection-ui.smoke.mjs`：修复前，创建并选择新账号后，连接失败提示不可见；修复后全部断言通过。真实 `PublishingConsole` 组件与 Edge 浏览器使用隔离的合成 API，覆盖创建后连接失败提示、原账号重试、后台轮询、多个账号错误隔离、设备离线与上线、未知设备状态，以及无账号时从发布视频页添加和重试。
- `npx vitest run tests/youtube-recovery-integration.test.ts -t 'R03 rejected offline begin'`：1 项通过，25 项跳过。使用合成端点确认离线连接被拒绝，不调用真实 Google，也不更改已有授权。
- `npm run verify`：退出码 0。类型检查、lint、148 个单元测试文件的 1540 项测试、14 项存储锁测试、8 项部署脚本测试、Next.js 生产构建和 Agent 构建均通过。
- `git diff --check`：通过。新浏览器回归脚本已独立通过 ESLint。
- 未执行真实 OAuth 同意、真实上传、真实直播或线上部署；模拟接口和构建结果不代表这些真实环境已验收。

## 本机故障取证与恢复（2026-10-29）

在用户授权重装的电脑上安装正式 0.1.19，安装包 SHA256 与网站构建清单和 GitHub 正式发行摘要一致；安装前后数据位置、根标识和加密配置文件摘要一致。用户自行登录后，客户端仍无法启动 Agent，实际提示“已有进程使用本机 Agent 配置”。

只读核查发现 `state/host.lock` 来自 10 月 22 日，所记 PID 已被 10 月 29 日创建的无关程序复用。核对进程镜像、创建时间、锁文件内容与时间，并确认无目标 Agent 后，将这一个旧锁移动到本机备份目录。未终止无关进程、未覆盖原配置。通过客户端原有“重新连接”恢复后，新的 Agent 进程持有新锁，客户端明确显示“设备在线”，原设备配对保留；网页刷新后原待清理账号由既有流程完成清理。

这是人工取证后的单机恢复，不是通用宿主锁修复。当前 PID-only 锁在进程号复用时仍可能误判；后续应独立实现进程创建身份与锁所有权核验，不能仅凭文件年龄或进程名称自动删除锁。本次不改写宿主锁协议、不发布新桌面包。

设备恢复后，使用网页已有未连接账号的“连接频道”实际进入 Google 账号选择页。只验证授权发起链路恢复；账号选择、OAuth 同意与最终绑定尚待用户完成，未代替用户授权，也未执行开停播或上传。
