# 发布账号页布局预览

本轮保留 LiveNest 的字体、蓝白配色和原有账号协议，调整账号页面的信息结构。三套方案共用真实组件与合成数据，只在本地比选；尚未由用户选定最终布局，不代表现网已经更新。

## 三套方案

| 方案 | 账号排列 | 详情与操作 |
| --- | --- | --- |
| 列表与详情 | 左侧紧凑账号列表 | 右侧只显示选中账号，适合连续切换管理 |
| 账号卡片 | 两列卡片集中展示账号 | 选中后在下方显示详情，适合按频道浏览 |
| 紧凑表格 | 名称、状态、添加日期按列对齐 | 右侧固定宽度详情，适合较多账号 |

页面顶部只保留设备选择。账号的连接、重试、去发布视频集中在详情内；未连接账号以“连接频道”为主操作，已连接账号以“去发布视频”为主操作。授权管理与删除收进“授权与数据／账号数据”，只有用户展开后才显示说明和确认。设备离线提示在页面显示一次，连接错误随选中账号保留。

间距采用 8／16／24／32px 的组内与组间节奏。移动端将账号列表收为一个有标签的选择器，下方立即展示当前账号，避免滚过整页账号才能找到操作。

## 启动本地预览

在仓库根目录运行：

```powershell
node scripts/preview/publishing-accounts.mjs
```

默认地址为 `http://127.0.0.1:3160/`。顶栏可以切换三套方案；切换只改变布局，保留当前账号与编辑上下文。预览使用隔离的内存账号，包含已连接、未连接、需要重授权和清理中状态。添加账号只增加演示记录，连接、撤销与其他真实写入均被预览服务拒绝，不访问 Agent、Google 或现网账号。
