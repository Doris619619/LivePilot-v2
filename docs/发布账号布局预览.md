# 发布账号页布局预览

用户已选定方案三“紧凑表格”作为默认布局。本轮继续保留 LiveNest 的字体、蓝白配色和原有账号协议，精简详情文字并把删除入口移到账号行。三套方案共用真实组件与合成数据；方案一、二仅供本地比较，布局选择器不进入正式产品。这些改动尚未部署到现网。

## 三套方案

| 方案 | 账号排列 | 详情与操作 |
| --- | --- | --- |
| 列表与详情（比较用） | 左侧紧凑账号列表 | 右侧只显示选中账号 |
| 账号卡片（比较用） | 两列卡片集中展示账号 | 选中后在下方显示详情 |
| 紧凑表格（已选默认） | 名称、状态、删除操作按列对齐 | 右侧显示当前账号的详情与主操作 |

页面顶部只保留设备选择。详情集中呈现账号名称、状态以及连接、重试、去发布视频等操作；未连接账号以“连接频道”为主操作，已连接账号以“去发布视频”为主操作。每个账号的日期、编号等附加信息，以及“授权与数据／账号数据”折叠区均从独立账号详情移除。详情不再重复显示 Google 管理、隐私政策或服务条款链接。设备离线提示在页面显示一次，连接错误随选中账号保留。

“添加发布账号”先打开连接说明弹窗，确认后才创建账号并进入 Google 授权；取消不会创建记录。连接失败时保留该账号并就地重试，不重复创建；授权成功返回后选中对应账号并显示连接结果。已连接账号可展示频道头像并打开频道主页。本轮不申请邮箱权限，也不增加邮箱字段；授权范围仍以频道连接所需权限为准。

紧凑表格使用独立的删除列，垃圾桶按钮只针对该行账号。移动端将账号列表收为有标签的选择器，并为当前选中账号提供垃圾桶入口。删除先打开明确标注账号的确认弹窗，说明清理与授权撤销的影响；取消不会提交请求，确认继续使用原有清理协议，设备离线时仍须等待设备确认。

间距采用 8／16／24／32px 的组内与组间节奏，页面内容在最大 1320px 范围内居中。正式网页的隐私政策与服务条款继续由根布局的共享页脚提供，不依赖账号详情。独立组件预览不装载网站根布局，不能据此判断线上共享页脚是否存在。

## 弹窗与选中态反馈迭代

用户指出上一版弹窗文字过多、间距松散且缺少重点，同时不希望账号选中行显示蓝色外框。本次将删除对象直接放进标题：从未连接的账号只显示“删除后无法恢复。”；有历史授权的账号保留两项关键后果，即同一 Google 账号下的直播与其他频道可能需要重新授权，以及已排期视频仍可能公开、YouTube 视频与本地文件保留。删除按钮改为红色实心主操作，取消保持次级样式。

两类账号弹窗采用专用的最大 440px 宽度与 24px 内边距，标题到描述 8px、补充正文前 16px、按钮区前 24px，避免共享描述外边距与内容间距叠加。添加弹窗移除重复的“发布设备”信息，设备仍由页面顶部选择；关闭按钮不再撑高标题行。未发生错误时不占用错误区域。

选中账号改用浅中性色背景与 600 字重，紧凑布局只保留行分隔线，不再绘制蓝色外框；鼠标悬停仍保持选中态稳定。键盘操作继续保留 `:focus-visible` 焦点提示。这些样式仅作用于账号工作区及其弹窗，不改变其他页面的危险操作按钮。

## 启动本地预览

在仓库根目录运行：

```powershell
node scripts/preview/publishing-accounts.mjs
```

默认地址为 `http://127.0.0.1:3160/`，仅监听本机回环地址。顶栏可以切换三套方案；切换只改变布局，保留当前账号与编辑上下文。预览使用隔离的内存账号，包含已连接、未连接、需要重授权和清理中状态。确认添加只增加演示记录，后续连接显示预览拦截提示；连接、撤销与其他真实写入均被预览服务拒绝，不访问 Agent、Google 或现网账号。频道头像使用本地生成的合成 SVG，不请求真实频道头像。
