# OBS 纵向配置

本次调整针对本地执行机“设备配置”中的 OBS 配置区域。原界面在顶部列出五步进度，下方又完整展开五步和完成徽章；改为标题兼入口的单列纵向步骤，每次只展开一步。当前为代码与本地预览交付，尚未发布安装器或替换已安装客户端。

## 使用行为

- 保留准备 OBS、连接网页、检查 OBS、连接频道、准备素材五项，每个 OBS 分别反映当前状态。
- 首次展开进入首个未完成项；全部完成时默认进入检查 OBS。用户可随时回访其他步骤，不增加顺序锁定。
- 折叠步骤在标题显示完成状态；展开且已完成时省略通用“已完成”，由内容显示具体结果，进行中和错误状态仍在标题提示。移除顶部横向五步栏、展开内容中的重复标题及右侧完成徽章。
- 同一时刻仅展开一个 OBS 的一个步骤。切换步骤、OBS 或本地导航只隐藏配置面板，保留配对码、表单输入和组件本地状态。各字段沿用原有保存规则，例如实例名称仍在失去焦点时保存；切换不会执行配对或开播。
- 读取新状态不会强制切换当前步骤。等待、失败和需要处理的问题仍须可辨认，连接结果与操作保持在目标 OBS 内。
- 正常连接采用用户选定的“折叠详情”结构：状态徽记、连接标题及 `HH:mm` 确认时刻组成一个信息组，描边“重新检查”和浅灰“查看详情”按钮在右侧同行。窄窗口将信息组放在首行，两个操作放在第二行，不挤压或拆开按钮文字。
- 详情默认收起，展开后用浅灰区域中的键值行显示实际连接状态、配置端口、完整确认时刻及已有的启动检查用时；不补造认证或延迟数据。启动耗时明确属于保存的启动轮次，不作为刚刚复查的耗时。仅有成功观测时也有真实配置与确认信息可查。启动中和失败的阶段、预算与恢复说明继续保留。
- 复查按钮带刷新图标，点击后立即显示“正在检查…”并禁用重复提交；进行中显示宿主实际阶段、已用时间与剩余检查时间；常规观测放在默认收起的“查看详情”中，复查最多 15 秒，启动检查最多 60 秒。倒计时是超时上限，不能按倒计时推进阶段或宣称连接成功。结束后收回过程，原按钮显示 4 秒“检查完成”，随后恢复“重新检查”。失败保留问题原因和重试入口，不增加独立完成提示。切到本机 OBS 时共享原实例检查状态；检查完成不等于控制已连接。
- 频道和素材操作继续打开对应 OBS 的网页配置；电脑配对仍属于整台电脑，新增 OBS 无需重复配对。
- 高级设置继续提供原有命名、路径、端口和连接修复能力。关闭客户端或刷新页面后的草稿持久化不属于本次承诺。

## 实现与无障碍

步骤内容使用稳定实例 ID 和固定面板保持挂载，折叠面板通过 `hidden` 隐藏并退出键盘与辅助技术的可交互范围。标题使用原生按钮，通过 `aria-expanded`、`aria-controls` 关联对应面板；支持 Enter、空格及清晰的键盘焦点。每个实例的配对控件使用唯一 DOM 标识，避免多个面板同时存在时标签指错对象。

布局沿用现有字体与语义颜色，复查按钮用描边突出操作，次要详情用浅灰按钮区分层级。详情使用原生按钮、`aria-expanded`、`aria-controls` 和唯一关联区域，支持 Enter / 空格及可见焦点；折叠时区域使用 `hidden` 退出焦点范围。连接模式变化后重新默认收起，复查按钮与播报节点保持稳定。不增加第二层侧栏，窄窗口及缩放后的有限宽度仍使用同一单列结构。
