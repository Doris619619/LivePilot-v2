## 用户可见变化

每个直播实例增加独立的 **AI 观众互动** 面板，由直播电脑持续运行，关闭网页后继续互动。首次默认开启，条件就绪后以当前频道回应新文字留言、欢迎首次发言者，并使用观众的语言；每条回复包含 `[AI]` 标识和观众称呼，最多 200 字符。

直播期间可独立开启、关闭、调整友善陪聊、活泼幽默、安静温柔或自定义人设，设置跨场次和重启保留。发送间隔默认 5 秒，可改为 5–60 秒，不设每日回复条数上限；YouTube 项目共享配额仍生效。队列最多 100 条，超过 2 分钟或溢出的旧留言跳过，面板显示状态、等待原因、发送 / 跳过 / 排队数量及最近 30 条互动。

直接使用管理员部署环境的 `DEEPSEEK_API_KEY`，用户无需输入或保存 Key。环境未就绪时提示联系管理员；频道授权异常时保留检查授权入口。旧 Agent 显示升级提示，设备离线时明确当前状态未知。功能与环境配置说明见 [直播 AI 观众互动](../直播AI观众互动.md)。

## 运行、兼容与升级

独立 Agent、桌面内嵌 Agent 和 local 模式均拥有每实例的后台运行器，官方 gRPC `streamList` 接收聊天，`liveChatMessages.insert` 发送。运行依赖随 Agent 打包，协议描述内嵌，无需用户安装额外聊天组件。Cloud 负责权限、投递、审计和状态；YouTube 令牌及 DeepSeek 调用留在 Agent，环境 Key 只向已配对的有效 Agent 会话交付，不进入浏览器 DTO。

仅处理启用后的新留言，保存加密游标及发送记录，按消息 ID 去重并过滤本频道消息和重复刷屏。发送结果不确定时不自动重发；关闭、停播、换场次或退出会取消生成并清空待发送内容。已提交给 YouTube 的消息无法通过关闭开关撤回。每日配额耗尽后等待 YouTube 配额重置。

升级顺序为 **Cloud → Agent / 桌面安装器**。保留现有数据根、设备和实例身份、OBS、素材、加密配置、YouTube 授权及原发布任务；无原数据目录迁移。新 Cloud 兼容旧 Agent 心跳，未声明聊天能力的实例不接收新聊天任务；新 Agent 连接旧 Cloud 时不请求未知环境路由，沿用管理员提供的本机环境。

客户安装正式 0.1.13 后才获得内嵌 Agent 的聊天运行能力。升级继续使用现有安全退出与安装流程；直播、录制、状态未知或任务排空失败时不强制重启。需要手动覆盖安装时，等待任务完成、从托盘正常退出并沿用原数据位置。回退保留聊天检查点，旧版本不执行聊天；不恢复旧业务数据或撤销 YouTube 已发送内容。
