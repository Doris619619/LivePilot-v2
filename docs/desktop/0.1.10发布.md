# LiveNest 0.1.10

五步配置的完成标签统一放在右侧，频道和素材按钮保留在标签左侧；完成后仍可重新配置。OBS 的“启动并检查”和“重新检查”在展开、收起及控制成功后均保留，操作与反馈只指向原实例。高级设置集中展示程序路径、控制端口、实例名称和修复入口。

本版本包含 [PR #23](https://github.com/Doris619619/LivePilot-v2/pull/23)。不更改配对、账号权限、实例 ID、频道归属、数据目录或 Agent 协议；更新沿用现有 OBS、素材和授权。

## 发布同步

源码、GitHub 安装包及自动更新元数据、云端程序、网站下载目录和历史入口须核对到同一版本。使用新版本 0.1.10，不覆盖已经公开的 0.1.9。云端在新发行目录完成构建，切换前备份配置和业务数据，保留上一发行目录；回退程序不覆盖运行期间产生的业务数据。

安装包仍须通过一次性 Windows CI 用户中的真实安装、覆盖升级和保留数据卸载检查，并完成上传后回下载校验。网站只有在对应安装包与构建清单就绪后才切换，避免新下载链接指向缺失资产。

## 验证与当前状态

- PR #23 修正已通过完整 verify（58 个测试文件、388 项测试、8 项部署测试）、桌面 renderer 构建、本地 Windows 打包及包后检查。
- 双 OBS 隔离浏览器验收通过：独立五步、共享配对与输入保留、控制成功后操作常驻、目标绑定、失败恢复、键盘和 780/1280px 布局。见[模拟数据截图](screenshots/completion-layout/controls-780.png)。
- 0.1.10 的最终验证、发布提交、公开安装包摘要及云端切换结果将在发布 PR 中记录；本文件不将准备工作视为已公开发布。
- 准备发布时，GitHub Actions 报账户付款失败或支出上限不足，Windows 安装验收及正式发布需待 CI 恢复后完成；本地打包不能替代该检查。
- 未执行真实 OAuth、生产直播、用户设备重新配对或强制重启现有客户端。客户电脑需在本机安全条件满足后通过更新入口升级。
