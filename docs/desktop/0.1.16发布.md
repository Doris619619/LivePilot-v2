# LiveNest 0.1.16

状态：源码检查通过，等待正式构建与部署；未将预览或单元测试写成线上验收。

## 用户变化

- OBS 启动显示真实阶段、慢等待、超时及后续恢复，连接成功后弱化重复启动操作。
- 直播第 3 步顶部集中放置本场运行状态、开播、重试与结束入口；执行中不显示重试，未知结果先检查。
- 封面预览默认完整显示当前卡片，展开后适配完整首页画布。
- AI 生成回复不再被发送端残留的 `[AI]` 强制前缀检查拦截；回复保持观众称呼和原有长度上限。

## 验证

- 本机 `npm run verify` 通过：115 个测试文件、1090 项测试、8 项部署检查及 Web / Agent 构建。
- 浏览器合成验收覆盖 390 / 780 / 1440px 的就绪、执行中、未知、失败、直播与恢复；聚焦和无横向溢出通过。
- 真实生成器到运行器的串联测试确认三条中文留言都到达模拟发送端；空白和超长仍拒绝。
- 未通过测试发起真实开播、OAuth 或向 YouTube 发送消息。实际客户端升级、Cloud 切换和正式安装器身份在部署完成后补记。

## 数据与升级

沿用原账号、设备、OBS、配对、频道授权、素材与任务数据，无迁移。Cloud 在独立版本目录构建，切换前备份，失败仅回退代码；桌面端必须升级才能让聊天修复生效，不能仅刷新网页。保留正在运行的本地预览和原服务，升级前核对实际任务与推流状态。
