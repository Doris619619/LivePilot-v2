# LiveNest 0.1.9

每个 OBS 都拥有完整的五步配置：准备 OBS → 连接网页 → 检查 OBS → 连接频道 → 准备素材。移除页面顶部共用的进度线；各实例独立显示已完成步数和下一步，点击步骤只展开、定位原实例。一次展开一个实例，另一个保留进度与启动入口。

电脑只配对一次；连接成功后，每个 OBS 的第 2 步均显示完成。切换实例不会清除尚未提交的配对码，也不会重新配对。频道和素材仍各自配置，素材备齐后须在网页选择本次文件再开播。

恢复原有字号层级：说明文字和输入框 16px，步骤标题 18px，普通按钮 15px，状态文字 14px。继续使用原 LiveNest Sans SC 字体，不修改系统或客户端缩放，也不为挤进窄窗口缩小正文。
