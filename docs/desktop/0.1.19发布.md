# LiveNest 0.1.19

## 版本范围

本版汇总已合并的 PR #44–#48：OBS配置和真实检查进度、网页工作台、YouTube配额保护与管理员数据台、灰色素材恢复，以及直播、发布、上传和桌面事务的异常恢复。逐项修复证据见 [main审计修复与验证](../main审计修复与验证.md)。本次版本提交仅同步package和lockfile版本，不追加业务逻辑或配额策略。

PR #48 合并为 `5ba77f9078faa0a771b14978ff931470c65ceb5f`，其代码树与已验证的 `5b25dec` 一致。版本准备时，该修复已有149个文件／1,554项测试、8项部署检查、Linux／Windows CI及Windows安装器检查通过；11条成员上传完整浏览器操作链及生产包页面回归通过。这些证据不代表本版正式安装资产已发行。

## 交付顺序

先部署包版本仍为0.1.18的兼容Cloud，保留现有下载目录；验收后再给0.1.19版本提交建立稳定标签，执行正式Windows发布。公开资产和CI清单核对后，先原子安装网站0.1.19下载目录，再切换最终0.1.19 Cloud，避免网站指向缺失安装器。

正式流水线要求版本、标签、源码SHA、干净构建清单一致，包含真实NSIS安装、覆盖升级及保留数据卸载检查。安装器、blockmap和latest.yml均需对照CI清单与GitHub摘要，服务器完整下载后另验SHA256、大小及更新元数据SHA512。

## 升级与回退

Cloud、网页及Agent按协议能力协同升级；旧Agent缺少恢复能力时明确提示升级，不能把连接成功当成新恢复能力已启用。升级保留原设备身份、OBS实例、素材、频道和授权。此任务发布安装包，不自动安装到当前电脑，也不触发真实OAuth、广播控制或视频上传测试。

发布后的程序回退底线为已验收的兼容Cloud `5ba77f9078faa0a771b14978ff931470c65ceb5f`，保留最新业务数据。不能盲退现网旧0.1.18：旧schema不接受新的授权状态，且旧授权失败路径仍可能启动清理。回滚程序不等于撤销外部写入，也不能用历史数据备份覆盖现有任务或凭据。
