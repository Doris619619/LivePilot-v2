# LiveNest 0.1.17

状态：正式安装包、官网静态下载与 Cloud 0.1.17 已发布；本机客户端升级待手动操作及核验。

## 功能

九种人设、场景接话和 Agent 试聊；桌面与手机支持选择、试聊、比较、保存并应用。试聊保留最近 16 条带人设标识的结果，比较可不带上下文。底部明确草稿状态；收起编辑区保留本页草稿。

需要升级 Agent 才能执行新接话策略和试聊。升级沿用账号、配对、实例、OBS 与频道授权；正在直播的电脑不强制重启。
