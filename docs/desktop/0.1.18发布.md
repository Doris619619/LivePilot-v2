# LiveNest 0.1.18

状态：正式安装包已发布，Cloud 已部署；用户已完成本机客户端升级，核实可执行文件为 0.1.18.0，实际 Agent 隔离试聊完成。

## 行为

电台以熟络口语接话，守夜人轻声回应但不要求观众安静，文艺只取一个小画面。歌名回答区分未知和未命名，不把缺少已知链接说成无法搜索；明确错字顺着原意回复，歧义短句只做简短澄清，明确问词义仍正常解释。

已知赶客、留客、虚构记忆和试听断言触发一次重新生成，仍不合适则拒绝输出。与语言修正共用一次重试预算，不循环请求、不替换固定回复；可能增加一次模型调用和延迟。原配置结构及授权不变，需要配套 Agent 更新。
