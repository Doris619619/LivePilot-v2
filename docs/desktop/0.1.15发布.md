# LiveNest 0.1.15

**状态：2026-10-16 已正式发行、部署 Cloud/网站并升级本机。** [PR #38](https://github.com/Doris619619/LivePilot-v2/pull/38) 与 [PR #39](https://github.com/Doris619619/LivePilot-v2/pull/39) 已合并。标签、正式安装器、网站资产与 Cloud 同源提交均为 `88ecf261e14443e0e94f6810960d12a54f3a9fbc`。本记录的后续文档提交不改变发行程序。

## 用户变化

- 直播按「素材选择 → 直播编排 → 开播」准备，完整配置是本场唯一依据；互动参数进入直播编排。
- 两类工作台共享设置中心，固定窗口、分类导航与内容滚动；切换保留草稿、步骤、位置和上传。
- 直播与视频发布配置包按账号复用；设备、频道及频道专属资源在使用时选择。设置提供明确新建/编辑入口。
- 视频配置包只管理规则，标题、说明及 AI 生成开关、语言、要求归属于实际发布流程。
- 账号共用 AI Key，分别控制文案生成和观众互动；凭据不回显，旧配置与授权保留。
- OBS 启动等待期间显示进度，完成后按最新观测显示结果，保留失败原因及恢复按钮。

## 发布审计修正

1. 新隐私版本任务不再投递到无法解析的旧客户端。新确认要求 0.1.15 能力；旧任务保留原快照并继续兼容。客户端协商可依次回退到 0.1.14 和更旧 Cloud。
2. 新 Agent 会话先撤下前一会话的账号 AI 凭据并取消旧回复，再同步新配置；失败保持停用，避免沿用错误账号 Key。
3. 生产依赖升级到安全修复版本，具体审计结果见下方验收记录。

## 配套与数据边界

先上线兼容 Cloud，再升级客户端。0.1.14 可继续运行旧任务，但新的视频发布确认和带互动配置的直播需要新版客户端。原账号、设备身份、OBS、授权、素材和历史计划不删除；旧模板只读迁入账号目录，新配置不覆盖已确认任务。

Cloud 发布在独立 SHA 目录构建、核对源码清单后切换程序软链接，切换前停止 Cloud 并备份配置和业务数据。回退只切换程序，不能用旧备份覆盖最新业务数据。保留当前及上一正式版本的完整目录。

`OBS_school_1` 的旧观测与此前授权跳过的快照哈希完全一致；只沿用这项精确豁免，不放宽任务、维护、身份、发布任务和服务健康门禁。所有设备缺乏新鲜观测，不据此宣称真实直播连续性。
