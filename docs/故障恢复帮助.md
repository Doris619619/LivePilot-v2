# 报错时如何处理

先看提示中的电脑、OBS 和文件名，再看本次结果。**“结果待核对”不代表操作没有执行**；先查询原操作及外部实际状态，不重复开播、切换频道、上传或迁移。

| 现场提示 | 下一步 |
| --- | --- |
| 设备在线，但 OBS 控制连接未建立 | 在提示指定的直播电脑和 OBS 中打开“工具 → WebSocket 服务器设置”，检查启用、端口和密码。点击该实例的重新检查。与是否有声音、是否开播无直接对应关系。 |
| OBS 未运行 | 确认原实例后点击“启动并检查”。此动作只启动程序，不开播。 |
| 控制端口被其他程序占用 | 核对原 OBS 端口；托管 OBS 的修复须先确认直播与录制结束并关闭该 OBS，不要结束不明程序。 |
| 控制密码不匹配 | 在桌面修正原候选的连接；失败保留输入，成功后清除密码输入框。 |
| 频道查询或 Google 服务失败 | 保留原授权，检查直播电脑的网络和代理后重新读取。只有明确授权失效才重新授权原频道。 |
| 状态过期、查询失败或操作结果保存失败 | 当前推流状态未知。在原 OBS 与 YouTube Studio 核对场次，再查询原任务。不要把旧快照当成停止推流的证明。 |
| 视频或音乐目录读取失败 | 检查原数据盘、Windows 账户及目录权限。读取失败不等于空库，不要重新建立设备身份。 |
| 上传已传完但校验失败 | 展开原上传，先查询校验状态。处理磁盘或权限后明确重新提交校验；文件损坏时取消原上传后选择原文件重传。 |
| 数据已切换但网页未恢复 | 原数据保留，使用“重新连接并恢复”，不要重复迁移。复制失败且重连也失败时先处理提示保留的原复制原因。 |
| 更新下载失败 | 当前版本仍可用；网络或磁盘恢复后重试下载。校验或签名失败交给管理员，不绕过校验安装。 |
| 维护被阻止 | 核对提示点名的电脑、实例、文件或授权期限；不要强制解锁。有未结束直播或录制时先按正常流程处理。 |

网页只能提供目标电脑上的操作步骤；在网页打开连接设置不会远程打开另一台电脑的系统窗口。桌面帮助可按 OBS、数据位置与恢复主题查阅。

“重新检查”“查询校验状态”和“查询本次操作”均为读取。若需要结束原场次、重新提交校验或重新授权，必须使用对应明确按钮。暂停与取消使用中性提示，取消浏览器等待不会取消已发出的服务端操作。

联系管理员时使用“复制诊断摘要”。摘要包含原因码、来源、原对象、阶段、结果、时间及尝试标识，不包含凭据或本机完整路径。

## 非阻塞检查

“防火墙隔离尚未确认”表示辅助技术检查没有确认保护策略，不表示 OBS 控制或直播失败。0.1.8 起它只进入技术报告，不再显示故障警告、不阻塞准备完成或开播。正常未启动、待配置与取消也使用中性状态。真正影响控制、频道、素材或任务结果的问题仍在对应 OBS 显示恢复操作。

管理员在“客户账号”创建客户、设置初始密码或重置客户密码。重置会撤销该客户旧会话，设备、频道和素材保持不变。Do 使用客户入口。
