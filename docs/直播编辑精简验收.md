# 直播编辑与表单文案精简

## 复审结论

前序改动逐块减少边框和说明，却未充分控制整页层级：生成工具、标题编辑、互动监控和预览故障占用相近的视觉分量；成功反馈、撤销和设置入口又各占一行。问题不仅是文字过多，也包括次要内容默认展开、重复状态标题和缺乏统一的字段辅助信息位置。

本次按 Impeccable 的 clarify / distill 指引调整已有功能，保持直播内容编辑为主任务；待机面板压缩，故障与恢复操作不藏进折叠区。

## 逐项改动

| 区域 | 改动 |
| --- | --- |
| 直播标题 | 删除「显示在 YouTube 直播页面」，计数右对齐，位于输入框下方 |
| 直播说明 | 计数同样右对齐；占位提示缩为「直播简介与相关链接」 |
| 长度状态 | 90% 起提示接近上限，超限显示具体超出量；保留原有字符/UTF-8 字节算法和读屏关联 |
| 文案生成 | 「文案主题」有固定标签；主题、生成英文文案、API 设置共用工具行；成功反馈和撤销同排，去掉独立底部分隔线 |
| 互动控制 | 标题、状态和启停合并；活动记录、互动设置、刷新共用一行；删除重复「自动回复观众」「互动状态」标题 |
| 互动记录 | 等待直播/关闭等非运行状态默认收起统计和记录；运行时默认展开，用户可切换且选择保留在当前挂载面板；故障、授权恢复、重试和离线提示始终可见 |
| 互动帮助 | 工作台不再单独放一整块说明；独立服务、关闭网页后继续运行、队列和配额规则合并到互动设置的帮助中 |
| 预览故障 | 去掉大块灰底和多层更新说明；保留原因、下载客户端和重新读取操作 |
| localhost 演示 | 未接入真实素材时明确说明「本地演示未连接真实素材」，避免误报客户端版本旧 |
| 发布设置 | 删除儿童选项下的泛泛提醒和空播放列表下对字段用途的重复解释；保留儿童聊天限制、公开范围、已有列表和空结果处理 |
| 发布编辑 | 计划编辑、批次覆盖复用长度计数，统一「字节」；保留留空回退、非法字符验证和上传确认 |
| API / 互动设置 | 删除已有状态标签已表达的「无需重复填写」及表单内容自明的介绍；密钥安全和验证边界仍在配置说明中 |
| 窄屏导航 | 删除视觉上重复的导航介绍，保留读屏描述 |
| 整页滚动 | 视觉验收发现收起的表单中，读屏文字的绝对定位撑出了正文后的空白滚动区；将定位限制在折叠容器内，保持表单挂载与草稿 |

## 验证

浏览器使用合成账号、设备、媒体和 API；不执行真实开播、OAuth、AI 计费调用或真实 Agent 上传。

| `node tests/live-chat-ui.smoke.mjs` | 通过：运行时默认展开、Enter / Space 收起与展开、启停和设置保存、授权恢复、离线和旧客户端、320 / 390px |
