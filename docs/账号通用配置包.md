# 账号通用配置包

## 用户行为

「设置 → 发布配置」在直播与视频工作台均提供两种配置包，不需要设备在线或频道授权。直播保存公开范围、儿童选项、视频原声和 AI 观众互动；视频保存可见性、儿童选项、封面策略、标签和其他发布规则。

使用时再选择设备与频道。直播完整配置继续保存本场播放列表，套用模板不会覆盖它。视频在「配置与排期」选择本次频道的播放列表；固定封面策略需要填写当前电脑中的图片文件名。切换配置包、频道时专属草稿分别保存，不带入其他频道。服务端生成计划时重新核对设备归属、发布账号、频道与模板修订。

## 配置包入口与文案边界

两类配置均先显示已保存列表与主按钮「新建…配置包」，每项显式「编辑」。直播还支持复制、确认删除；编辑名称即可重命名。编号仅出现在编辑表单中，保存和返回靠近表单底部。移除账号通用说明与管理折叠，不用「另存为」代替新建。

视频包不再配置标题模板、说明模板、模板变量或 AI 失败兜底文案。具体标题与说明来自每条素材包或本次发布编辑。AI 生成开关、语言和生成要求移到实际发布流程的「配置与排期 → 视频文案」，默认关闭，与本次草稿一起保留；切换配置包不会覆盖，修改后须重新生成计划。旧模板字段仍兼容存储；新计划不再套用旧的固定文案，缺省使用素材包名和空说明，人工/素材包文案优先。已经生成的计划与任务保持原快照。

## 存储与迁移

- 直播：`broadcast-profile-library/<登录账号 SHA256>/profiles.json`。模板和迁入标记同一文件原子保存，修订冲突返回 409。
- 视频：`publishing-templates/<登录账号 SHA256>/templates.json`，新的 `/api/publishing-templates` 只接收通用字段，拒绝设备、频道、播放列表、封面文件名及所有者注入。
- 账号目录只由服务端会话身份确定。管理员的个人模板与其他客户隔离；模板授权不能替代执行目标授权。
- 旧视频规则按原 `owner` 复制，原 `cloud/publishing/state.json`、计划、任务和授权不改写。移除旧设备不会删除新账号模板。重名自动增加迁入后缀，原样重试与重复读取不产生重复配置。
- 旧直播目录采用账号、设备、实例、频道的联合摘要，且没有反查元数据。自动迁入用现有频道绑定、设备心跳、旧发布记录和兼容请求中的目标线索计算当前账号的旧目录；只读匹配文件，不枚举后猜测归属。找不到线索的旧目录仍原样保留，管理员可用已知原目标向旧兼容 GET 提供线索（须以原账号访问），不能把所有匿名目录归给当前账号。
- 迁入标记与新模板原子保存，之后删除/编辑不会被旧文件复活或覆盖。源文件仍保留旧播放列表、封面、文案和素材引用，新模板只保留通用参数。
- 已有发布计划和 Agent 任务继续使用原有完整 `PublishingProfile` 快照，执行协议没有放宽。旧 API 仍支持旧版绑定 Profile；新模板不会自动改写旧客户端正在编辑的 Profile。

## 验证边界

本次新增账号无设备 CRUD、跨账号/管理员隔离、旧文件不变、幂等迁入、并发修订及固定封面延后绑定测试。计划集成测试使用合成 Agent RPC，验证同一模板跨设备/频道使用、目标权限重查、旧计划不变；不等于实际 YouTube 发布验收。

浏览器验收使用 localhost 的隔离目录和合成业务数据，不执行真实开播、OAuth、付费 AI 或上传。模板 API 使用真实文件存储；保存失败通过浏览器拦截模拟。完整检查及浏览器结果在 PR 中记录。
