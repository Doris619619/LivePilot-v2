# 前端回归检查（2026-10-10）

检查使用本地生产构建与隔离演示数据。依据用户提供的 P1 / P2 对照，首先恢复直播编辑面板的边框与内容层级，再检查相邻页面。自动化测试通过不代表视觉验收通过。

## 已复现并修复

| 问题 | 修复 | 复测依据 |
| --- | --- | --- |
| AI 区块新增圆角框但无内边距，文字贴边；页签外框叠在编辑卡片上 | 单层编辑外框、下划线页签；AI 只保留底部分隔线，内容共用 24px 面板留白 | 实际桌面截图；AI 背景透明，左右边框为 0 |
| 开播控件移入第 4 步后仍携带原侧栏卡片外框 | 去掉内框和重复 padding；操作按钮按内容排列 | 第 4 步内框计算边宽为 0，面板 padding 为 24px |
| 窄屏顶栏固定 60px，高度不足以容纳换行；客户端顶栏强制不换行 | 顶栏自动高度；客户端按钮允许换行 | 320px 页面，Web 顶栏底部 103px、操作区底部 92px，导航从 103px 开始 |
| 768px 时侧栏仍可见，第四个直播页签被面板裁切 | 1000px 以下提前采用四列等宽页签 | 768px 页面，页签最右边界 684px，小于容器 698px |
| 客户端设置页文件操作区不能收缩，按钮撑出页面 | 允许操作组收缩、换行并限制最大宽度 | 320px 下三按钮全部在设置页内 |
| 关闭手机导航或切换屏幕宽度会卸载配对组件，电脑名称草稿丢失 | 配对 Hook 由工作台持有，视图可卸载；邀请仍只在内存中 | 输入“检查用草稿”，关闭重开、320px 切到 768px 均保留；未生成配对码 |

## 检查矩阵

| 区域 | 实际检查 | 结果与边界 |
| --- | --- | --- |
| 直播内容 | 单层边框、标题/说明对齐、封面区、四步切换 | 修复后的桌面截图已替换；保留原有单文件上传业务 |
| 音视频 / 发布设置 / 开始直播 | 三个面板的最终渲染、键盘右方向键、控件布局 | 方向键移动焦点并选中音视频；未点击开始/结束直播 |
| 上传面板 | 展开/收起、320px 单列目标选择与拖拽区 | 无页面横向溢出；未传输真实文件 |
| AI 互动 | 设置 / 活动记录展开收起、常驻状态与故障入口 | 演示记录可见；未发起真实聊天 |
| 发布向导 | 素材列表、时间设置、月份计划、配置编辑 | 桌面和 320px 表单布局检查；未确认发布 |
| 排期抽屉 | 打开、关闭、编辑内容与内部滚动宽度 | 320px 下抽屉 clientWidth 与 scrollWidth 都为 294px |
| 我的发布 | 批次详情、六阶段状态、进度、删除确认与取消 | 确认框内容及保留批次可用；未删除批次 |
| 管理员 | 设备 / 客户页签、表格、账号输入 | 320px 表格局部滚动，整页不撑宽；账号输入跨页签保留，未创建用户 |
| 客户端 | 设备配置、设置、导航抽屉、文件动作组 | 浏览器静态桥接预览检查；不等于 Electron 安装包实机验收 |
| 登录 / 下载 | 表单、主入口、320px 页面宽度 | 页面 scrollWidth 为 300px，不超过 320px 视口；未登录或下载 |

检查宽度包含桌面默认宽度、1024px、768px、391px 和 320px（CSS 像素）；并非每个页面在每种宽度都逐一覆盖。浏览器截图在动画结束后读取；焦点描边属于键盘交互反馈，不作为装饰边框移除。
