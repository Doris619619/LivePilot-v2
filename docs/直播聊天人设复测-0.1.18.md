# 0.1.18 人设接话复测

## 结果与边界

修改前：0.1.17 正式 Cloud → 本机 Agent 的隔离试聊，36 条结果，另有 3 次限频失败后补测。修改后：当前候选源码的真实生成器、真实 DeepSeek 模型，36 条同题加 12 条边界样本全部返回，未连接 YouTube、未写实例配置。不是候选客户端已安装的证明；部署和实机结果见 [0.1.18 发布记录](desktop/0.1.18发布.md)。

统一使用 responsive、空历史、默认表达设置；频道背景为 AI 生成、未命名、无已知检索链接。自定义样本为唱片店老板，属于显式测试描述，不是第九个内置人设。以下保留整轮结果，仅移除统一 @试聊观众 前缀；没有从多次生成中挑选单条。

审阅：电台更口语，守夜人不再让人安静，文艺转为短画面。事实问答和澄清允许接近，不为了区分而附加梗。创意质量仍有波动，不把一次结果称为稳定质量保证。此前迭代曾出现歧义词解释、未知标题误判未命名、留客和虚构记忆表达，均保留本机日志并据此修正规则；本表只比较最终候选整轮。
